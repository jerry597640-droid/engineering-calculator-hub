滑動查詢圖形數值

  1. 分析完成後，拖曳「滑動查詢斷面」滑桿，或在剪力、彎矩、撓度圖上左右滑動。游標、各圖旁數值及梁配置圖同步定位，且不修改輸入模型或車位。
  2. 也可輸入x精確查詢。方向鍵微調，按Shift加大步幅，Home／End到梁端。在支承、集中力或彎矩位置，切換左／右側可查跳躍前後的值。
  3. 目前車位曲線採精確截面求值；包絡採最近的計算取值站，顯示實際站位及原查詢位置，不在跳躍處插值。滑動查詢不會重新掃描車輛。

圖形如何對應輸入值

梁圖預設「原始輸入值」：標示各載重編號、位置、大小與支承座標；車軸標整軸重量。下方對照清單另列本梁作用值，包含組合係數；車軸另乘梁分配係數及衝擊加成。也可切換「分析組合作用值」或「使用組合作用值」查看相應值。圖上箭頭長度為辨識用示意，不當作共同的力大小比例。

編輯載重、支承或車軸欄位時，梁圖及對照清單會標亮對應項目。集中力向下為正、彎矩逆時針為正，負值箭頭方向相反；分布載重輪廓依兩端值變化。梁外車軸仍列於清單並標「梁外」，不施加於梁。

一、五步完成分析

  1. 模型與載重：輸入梁長、E、I，選擇支承或新增多個支承。固定端限制位移及轉角；鉸支承／滾支承僅限制垂直位移。
  2. 新增載重：集中力、集中彎矩或分布載重可同時使用；分布載重兩端值相同為均布，一端零為三角，兩端不同為梯形。位置一律從左端 x = 0 起算。
  3. 車行載重：開啟後輸入各軸重、相對基準軸偏距、衝擊加成、梁分配係數。先看目前車位，再執行車行包絡。
  4. 容量與撓度：選擇載重組合，輸入已計算的正／負彎矩容量與剪力容量、來源及採用基準。使用載重撓度另外以使用組合計算。
  5. 分析與檢核：輸入後自動顯示；需要時可按右上按鈕重新求解。讀取反力、內力圖、極值位置與檢核比。可匯出專案 JSON、CSV、計算報告 HTML，或列印成 PDF。

連續梁：2跨以上的快速設定

  1. 到「模型與載重」→「02 支承配置」→「連續梁快速設定」。填跨數2～11，按「建立分跨表」。
  2. 各跨長度由左至右分別輸入；等跨可填「全部同長」並按「全部設同長」。跨長資料取支承中心線距離、結構圖或現地量測，長度採m。
  3. 按「套用連續梁配置」，程式自動累加總長並建立n＋1個支承。左端預設鉸支承，其餘滾支承，沉陷重設0；下方仍可改固定端與沉陷。梁在中間支承保持連續。
  4. 全長分布載重延伸選項開啟時，原來覆蓋全梁的分布載重會延伸到新梁末端，q值保持不變。集中力、集中彎矩與局部分布載重保留從左端起算的原位置。縮短後如載重或車位超出梁長，會拒絕套用並保留原專案。
  5. 按「分析與檢核」取得各支承反力、正負彎矩與逐跨撓度。車行載重可跨過全部支承，另按「車行包絡」。

照填例：3跨填6、6、6，總長18m，支承位置0、6、12、18m；全梁w=10 kN/m、E=200000 MPa、I=8000 cm⁴，反力24、66、66、24kN，中間兩支承彎矩皆−36kN·m。不等跨可填4、6、5，總長15m，支承位置0、4、10、15m。也可直接按下方三跨、四跨及不等跨範例。

表格／欄位定義與填法資料來源
跨數、各跨Lᵢ（m）快速設定2～11跨；L=ΣLᵢ，支承位置依累計跨長建立。各跨須大於零；套用前屬草稿。結構平面圖、支承中心線及量測；各跨可不同。總長仍須0.1～1000m。
梁長 L（m）分析梁從左端到右端的總長；含懸挑段。淨跨或中心跨採法須與設計模型一致。結構圖、支承中心線、竣工測量。
彈性模數 E（MPa）分析使用的彈性模數；鋼材可用專案值，RC 須考量有效剛度及開裂。材料規範、試驗、結構設計假設。鋼材例200000 MPa為示例。
I（cm⁴）對應受彎軸的慣性矩；不是另一弱軸。等斷面、全梁共同值。型鋼表、CAD 斷面性質、RC 有效剛度分析。
A、S⁺、S⁻A 用於自重；S 用於彈性彎曲應力。正负容量與上下緣應力的對應須依斷面確認。型鋼廠資料、斷面計算；H型尺寸推算忽略圓角，不替代廠表。
γ（kN/m³）開啟自重時，wD = γA × 10⁻⁴（kN/m），歸入D。勿重複輸入同一自重。材料單位重、設備重量；示例77 kN/m³非所有材料通用。
支承 x、型式0 ≤ x ≤ L，可新增最多12個支承，兩端有支承時可形成最多11跨。鉸／滾支承不釋放梁截面的連續轉角。構造接合細節、實際支撐方式；一般座承不直接當固定端。
沉陷（mm）正值向下、負值向上；固定端轉角仍設0。模型包含支承沉陷造成的內力。測量、基礎沉陷分析、施工預拱／支承高程。

分布載重 a、b、q₀、q₁a至b內線性變化。面載重需乘分攤寬度：q = p × B。正值向下。樓板荷載、分攤面積、土壓／水壓分析；可自行輸入換算後值。
集中彎矩 C正值逆時針。正C造成M圖在該位置向下跳C，剪力不跳。設備偏心、次構件端彎矩、力偶或偏心反力P×e。

組合係數使用組合預設1D+1L+1X；RC重力示例1.4D及1.2D+1.6L，X係數0。自訂可設定各係數。適用規範與設計計算書；重力示例不含所有風、震、雨、雪及特殊組合。

軸重、分配係數η軸重是整軸重量；梁分配係數將整軸力分給本梁。軸作用P=軸重×η×(1+IM)。車型載重資料、輪距／梁距、横向分配分析；單梁不能自動假設整車均分。
衝擊加成IM輸入0.30表示加30%，靜力載重放大1.30。程式不由车速計算動態反應。適用橋梁規範、專案規定、路面條件與施工速度限制。示例0不代表設計車可忽略衝擊。
車位x₀、掃描步距Δx基準軸從−車長到L。包絡使用Δx及Δx/2，另納入車軸經過取值站的事件。指定車行路徑；步距由精度需求決定。加密差≤0.5%只是數值穩定指標。
M容許⁺／⁻、V容許以正數填正／負彎矩容量及剪力容量。ASD容量比使用需求；RC/LRFD比因數化需求。RC φMn／φVn計算書、鋼梁ASD或LRFD（含局部及側向挫屈）、既有設計工具。

四、計算方法與符號

採 Euler–Bernoulli 梁、線性彈性、小變形、全梁等EI。每節點有垂直位移及轉角兩個自由度；依支承位置組合元素剛度，對所有載重使用一致節點荷載。分布載重以三點高斯積分求等值荷載；集中力及力偶使用形函數及其導數。反力由 R = Kd − F 求得；截面V、M由實際載重與反力平衡回復，撓度以 EI y″ = M 積分回復，包含元素內載重影響。

集中力與彎矩作用點同時保存左／右側值；内力及撓度極值在載重区間內求導數根，並非僅比較繪圖格點。支承沉陷只作用一次，不隨D／L係數放大。未建模軸力、扭矩、剪切變形、二階效應、塑性、RC開裂歷程、內鉸、支承彈簧及抗拔接觸重分配。

六、車行包絡怎麼讀

包絡上緣／下緣為每個梁位置在所有掃描車位中的最大／最小值，不是同一台車在某個瞬間的完整內力圖。「控制車位」可載入對應車位，查看那一刻反力及圖形。車輛進出梁時僅納入梁上車軸；掃描範圍包含部分軸在梁上情況。反向行驶可分別檢查，程式不自動疊加多車道、多車併行或多台車。

掃描結果標示步距、位置數及加密差；差值超过0.5%應縮小步距再算。即使差值小，離散掃描仍可能低估真實連續包絡。圖形取值站與全梁控制極值分別列示。車行圖上的撓度若採強度組合，容量表的撓度仍來自另外的使用載重組合。

七、離線、手機、保存與匯出

  • 離線ZIP解壓後開啟 index.html；無CDN、無需安裝套件。所有計算與內嵌操作影片在裝置執行。外部規範及回到入口連結需要網路。
  • 手機螢幕先顯示結果，下方為輸入；上方功能可横向滑動。ZIP須先解壓並用可執行JavaScript的瀏覽器開啟，檔案預覽器可能不執行程式。
  • 資料會嘗試存於此瀏覽器；若儲存遭封鎖會顯示提示。換瀏覽器、清除資料或搬到不同位置時，請用JSON匯出／載入保留模型。
  • 修改後先顯示更新中，隨即重算目前位置；無效輸入時清空結果。車位滑桿會更新目前位置圖，已完成的包絡保留；其他模型修改會清除包絡。
  • CSV採UTF-8含BOM，可用Excel開啟；計算報告HTML包含載重、反力、內力圖及計算過程，可在瀏覽器列印PDF。不是原生DOCX檔。
