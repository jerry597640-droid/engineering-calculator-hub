操作流程

  1. 選擇工程／剖面名稱、輸入單位、分析方法與門檻。一般水保案件可選 §73 永久性或臨時性；建築物可參考基礎規範112年版之整體穩定門檻；本版僅分析地盤圓弧，未建模擋土構造物自重、牆體與補強。其他案件請用自訂並填寫採用條文。
  2. 從測量或 CAD 整理地表 x,y，以低側在左、高側在右排列。輸入真實高程或共同基準高程，所有資料使用同一基準。
  3. 按鑽探報告填水平土層層底高程，以及有效 c′、φ′、天然與飽和單位重。γ 的單位是力／體積，不是力／面積。
  4. 選水壓模式，分別填常時及暴雨水位。地震採常時水位；需考慮暴雨與地震共同作用時，另存專案將常時水位改為暴雨水位後分析。
  5. 填實際均布載重及位置，地震 kh、|kv| 依工址分析報告輸入。程式會比較垂直地震正負方向。
  6. 先用 60 片、搜尋密度 14 執行。再用 120 片、密度 20–24，比對 FS、臨界面及是否碰到搜尋邊界；必要時擴大剖面與深度範圍。
  7. 檢視三工況、切片數、殘差、未收斂與排除原因。負有效法向力表示簡化模型須另檢討張裂／接觸，介面不作「達門檻」結論。
  8. 儲存 JSON 專案，匯出詳細 Word 計算書、完整計算 JSON、HTML、CSV 與 SVG。Word 含三工況逐片 b、h、W、α、u、驅動／抗滑力及合計，並列 FS=ΣR/ΣD；另附代表切片代入、重量積分分項及全部迭代。HTML 可由瀏覽器列印成 PDF；下載離線版後直接用 Chrome／Edge 開啟。

方法、限制與常見問題

建築物基礎構造設計規範 112 年版如何配合？

國土署現行公告版本於113年1月1日生效。§7.4.4 擋土牆整體穩定門檻為長期 FS>1.5、最高水位 FS>1.2、地震 FS>1.1，最高水位可不與地震同時考慮。此選項只套用門檻；本程式地盤模型不含牆體、自重及錨力，完整擋土牆尚須另作滑動、傾覆、支承力及液化等檢核。§8.4.2 開挖邊坡須考慮地下水、施工超載、地震、逕流沖刷及周圍環境；本版不分析沖刷與變形，應另依案件補足。國土署公告與112年版全文 ↗

Bishop 與 Fellenius 如何選？

Bishop 簡化法假設切片間剪力為零，滿足整體力矩與切片垂直力平衡；未滿足完整水平力平衡。Fellenius 忽略所有切片間力，作為普通切片法比對。兩者限於本版的圓弧模型；不應把 Bishop 結果宣稱為 Spencer 或 Morgenstern–Price 完整平衡解。

地下水為什麼要分常時與暴雨？

水位上升可能增加重量並降低有效法向力。固定深度模式為地表以下等深的壓力水頭簡化；水位線模式可填觀測或設計壓力面。兩者不是降雨入滲或暫態滲流求解器，外部積水、快速洩降及超額孔隙水壓需另作分析。

負有效法向力或沒有有效圓弧怎麼處理？

不直接把負有效法向力截成零後宣稱平衡成立。本版保留計算值並標示「需檢討張裂」；應以張裂、接觸、非圓弧或完整平衡模型複核。沒有有效圓弧時顯示「無結果」，絕不視為安全。Bishop 最終 mα<0.2、未收斂及無驅動力矩的圓弧均排除並列入紀錄。

地表向左爬升、岩盤或土層傾斜怎麼輸入？

先鏡射 x 並重新由小至大排列，低側留在左。本版的土層界面為水平；傾斜弱層、順向坡、楔形／平面岩塊、落石、地錨與土釘補強、三維效應及液化未實作，不能用等效 c′ 取代完整機制檢核。

離線能做哪些事？

HTML 的 CSS、SVG 與計算程式全部內嵌，不需 CDN、網路 API 或安裝套件。計算、專案讀寫與輸出均可離線執行；規範原文與 YouTube 影片需網路。完整離線 ZIP 內附本程式操作影片及台灣女性旁白，解壓縮後開啟 index.html 即可播放。單檔離線版僅計算功能及說明可離線，影片需使用完整 ZIP。瀏覽器限制儲存時仍可用檔案下載保存專案。
