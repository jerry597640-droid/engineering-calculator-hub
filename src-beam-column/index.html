柱／梁柱：照著輸入的範例

  1. 切換「柱／梁柱檢核」，按「載入範例」。混凝土 b=h=80 cm，fc′=280 kgf/cm²，鋼骨 Fys=3500，主筋 Fyr=4200，Es=2,100,000 kgf/cm²。
  2. 置中 H 450×350×14×22 mm；欄位 hs=45、bf=35、tw=1.4、tf=2.2 cm，鋼材490級。幾何不含圓角，以板塊近似。
  3. 主筋12-D25：頂部 y=7、底部 y=73，各4支，x=7、29、51、73；兩側 x=7、73，各另加 y=29、51。每支標稱面積5.067 cm²，Ar=60.804 cm²。
  4. 箍筋D13、兩方向較小有效肢數4、間距15 cm、Fyh=2800 kgf/cm²；保護層4 cm、骨材2 cm。實際箍筋與繫筋肢數、錨定須以詳圖確認。
  5. 柱長360 cm、Kx=Ky=1；因數化Pu=400 tf。選已含P–Δ二階分析，輸入同一工況 Mx=60、My=20 tf-m。Tu=0。示範內力須用實際完整結構分析替換。

  7. 若一階分析，改選一階；Mntx=50、Mltx=10、Mnty=15、Mlty=5，Cmx=Cmy=1、θx=θy=0.05。本頁按B1Mnt+B2Mlt放大。θ是整層數據算得，示範值不能直接用於正式工程。

主筋表格

逐支填入x、y中心座標及CNS號數；號數自動帶入直徑與每支面積。使用同樣座標尺度的組合斷面／施工詳圖。變更一支座標或號數時，須同步變更其兩軸鏡射位置。新增對稱4支會在(x,y)、(b−x,y)、(x,h−y)、(b−x,h−y)各加一支，之後仍須確認淨距。補助筋不計强度，本版主筋表只填有效、連續或適當錨定的主筋。

判讀與適用範圍

柱固定採橫箍筋、矩形常重混凝土、置中雙對稱H鋼及雙對稱有效主筋；僅支援軸壓。強軸Mx對應沿腹板深度方向彎曲，弱軸My對應翼板寬度方向彎曲。採絕對值檢核，依雙對稱斷面反射對稱性處理符號；不能用不同組合的最大Pu、Mx、My混作實際工況。

RC柱應變相容採εcu=0.003、β₁等值壓力塊、鋼筋彈塑性。二維力平衡直接求雙向抗彎邊界，RC固定φ=0.65，未採拉力控制增加折減係數，屬保守設定。柱剪力、耐震圍束、強柱弱梁與接頭未自動完成；本頁即使P–M通過，仍須另完成這些項目。第七章容許的內力重新分配本版不啟用；初始剛度分配不通過時，顯示不足，可能需進一步分析而非斷面必然不可用。

輸入不成立、非對稱配筋、Tu非零或一階彎矩放大分母≤0時，清除結果並停止合格判定。材料、鋼骨比例、淨距、保護層、寬厚比或箍筋細則未符時，容量只供查核。接頭、施工階段、使用性、防火、裂縫、混凝土澆置可行性與工程荷載組合須另核。

  2. 主筋採四角雙層：頂部 y = 8、14 cm，底部 y = 66、72 cm，每層 2-D32，x = 7、43 cm。每面 4-D32，As = 32.572 cm²。
  3. 使用 2 肢 D13 @ 15 cm、Fyh = 2800 kgf/cm²；Avf = 2.534 cm²、μ = 0.8，不計剪力釘。

  5. 閱讀強度比值及適用條件；到「計算過程」看 c、a、逐支應變與力平衡。再到「配筋設計」搜尋並套用候選方案。

主筋兩種輸入方式

分層配置：輸入支數、號數、y 及第一／最後一支的 x，程式在兩端之間等距排列。單支時只採第一支 x。逐支座標：每支輸入 x、y、標稱直徑及有效面積，可安排不規則位置。從分層切換到逐支會轉換目前配筋；再切回分層則每支各自成一層。

座標必須是鋼筋中心，而不是保護層距離。保護層欄為混凝土面至箍筋外側；主筋中心到混凝土面的距離至少為保護層＋箍筋直徑＋主筋半徑。逐支有效面積請按 CNS／廠商資料，不能把總面積輸入到每一支。

剪力摩擦怎麼填

Av 是整組有效垂直箍筋面積，由號數×肢數自動計算。Avf 只計穿越假定鋼骨翼板剪力摩擦面的、已充分錨定鋼筋；不得大於 Av。μ 依施工界面選 0.8（整體澆置）、0.55（硬化面粗糙處理）或 0.35（未粗糙）。本版只支援常重混凝土。Vns′ 是沿該剪力摩擦面配置剪力釘的總標稱貢獻，沒有獨立設計依據時填 0。

判讀結果

  • 「本頁檢核通過」：本版涵蓋的強度、幾何與材料條件皆通過。
  • 「強度不足」：至少一項需求／容量大於 1，調整混凝土尺寸、H 鋼、主筋或箍筋。
  • 「不符合適用條件」：即使容量大於需求，也不能依本頁數值判定合格；先解決紅色構造項目。
  • 「需補充檢核」：耐震用途或未充分支撐的施工階段尚有本版未計算的要求。

本版範圍

矩形、常重混凝土、完全包覆、對稱翼板 H 型鋼、單向強軸彎曲、無軸力、無扭矩、無開孔。正彎矩為上緣受壓；負彎矩為下緣受壓。輸入需求來自完整結構分析，程式不自動組合地震／風力／施工荷載，不計樓板 T 梁翼緣作用。裸鋼施工階段、長期撓度、裂縫、接頭、伸展錨定、剪力釘設計、防火及第九章耐震設計另核。

計算模型與保守設定

SRC 抗彎依 5.4.1 強度疊加法。鋼骨採 Mns = Fys Z；RC 採平面保持平面、εcu = 0.003、矩形等值壓力塊及鋼筋彈塑性應力。以二分法求 RC 軸向合力為零。剪力有效深度 d 取受拉側半斷面主筋的面積形心（含該側各層），不將反向面偶然受拉的補助主筋納入 d。RC 壓力塊扣除實際占用的鋼骨與主筋面積及一階矩，避免重複計入混凝土；此為較使用全寬壓力塊保守的實作設定。兩個子斷面的中性軸不同，不將圖中的 RC 中性軸誤用於鋼骨。

SRC 5.4.1 折減係數為鋼骨 0.9、RC 0.9。本程式額外檢查 112 年 RC 9.3.3.1 的拉力控制 εt ≥ Fyr / Es + 0.003；未達時顯示不符合，並僅顯示採 RC 表 21.2.2 降低 φ 的參考容量，不會標成合格。

剪力依 5.5 分配需求；RC 抗剪包含一般剪力與剪力摩擦的較小值。2.12√fc′bd、0.53√fc′bd 及 K1 = 28 使用 kgf/cm²、cm 單位，不能把 MPa 直接代入。翼板寬厚比使用全翼板寬 bf / tf，腹板淨高 hs − 2tf；本版以直角組合板計算，忽略型鋼圓角。

柱／梁柱計算設定

依SRC6.4計算兩軸挫屈及RC長柱抗壓上限；SRC7.3按相對剛度分配外力，各子斷面分別驗算。RC柱採二維平面應變相容，直接扣除鋼骨與主筋占用的混凝土；固定保守φ=0.65，不採內力重新分配。柱剪力及第九章耐震設計另核。
