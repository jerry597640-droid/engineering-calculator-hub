操作流程

  1. 選擇單向剪力或沖切剪力；按「載入範例」可直接操作。
  2. 填寫材料、尺寸與鋼筋位置；每個欄位下方都顯示資料來源。
  3. 選擇需求來源：規則版的重力估算，或分析軟體的因數化剪力／應力。分析值不能再乘載重因數。
  4. 檢查臨界斷面、d、λs 與控制公式，確認 D/C。每個方向、柱位與載重組合均應各自檢核。
  5. 進入計算報告可列印／另存 PDF、匯出 HTML 計算書；「匯出專案」保存所有輸入，日後可匯入重算。
此工作台執行非預力實心樓版、無剪力鋼筋的剪力強度檢核。彎曲配筋、撓度、裂縫、錨定、耐震變形相容性與剪力筋配置須另行設計。特別幾何會停止判定，避免用標準周界誤判。

各表格要填什麼？資料從哪裡來？

表格／欄位填入內容資料來源與注意事項
材料與樓版工程名稱、版厚 h、fc′、λ、φ結構圖、混凝土規格與檢測、核准計算書。λ 依 §19.2.4，常重取 1；φ 一般剪力取 0.75，耐震特殊情況須核 §21.2.4。材料強度開根號上限自動取 26.5。
單向版帶bw、保護層 c、鋼筋尺寸 db、層位偏移、手動 d配筋剖面。c 量到該受拉筋外緣；偏移指受拉筋非最外層時增加的距離。自動 d=h−c−偏移−db/2。手動 d 為受壓緣到受拉鋼筋形心。
受拉筋鋼筋規格＋間距 s，或手動 As檢核斷面受拉側的實際縱向鋼筋；支承負彎矩通常為頂筋。不能把上下雙層相加。As=Ab×bw/s 為規則版帶等效量，有限寬版帶用實際筋數輸入 As。
單向需求簡支／懸臂、跨度 Ln；或直接 Vu；軸力 NuLn 為簡支支承面間淨跨度或懸臂固定面至自由端。Vu 與 Nu 取同一載重組合；tf 表示公噸力，Nu 壓正拉負。直接 Vu 必須已在所選檢核斷面取得；軟體輸出 kN 須除以 9.80665 換為 tf。
柱位／沖切周界內、邊、角柱；cx、cy；dx、dy結構平面、剖面。cx／cy 為柱或反力面的 X／Y 實際尺寸，不是柱距。dx／dy 量到兩方向受拉筋形心，d=(dx+dy)/2。邊柱自由邊位於 X 負向；角柱位於 X、Y 負向。
沖切需求淨 Vu；或因數化柱反力 Ru 與同組合 qu；內柱 Mx／My；或最大 vu結構分析相同組合之柱板傳遞力（勿把多樓層累積柱軸力當成本層反力）。反力模式使用另填的「同組合 qu」扣除周界內載重；不使用其他組合的最大 qu，避免混用組合。直接淨 Vu 不再扣一次。Mx、My 單位 tf·m，均以柱中心／周界形心為基準（內柱兩者重合）。
最大剪應力 vukgf/cm²，含剪力偏心、彎矩傳遞及形心偏移合格計算書、有限元素後處理或板柱接頭計算。邊／角柱必須使用完整最大 vu，不可只用 Vu/(b0d)。分析軟體一般元素剪應力不一定等於規範臨界周界應力。
重力載重γc、額外 D、L材料規格、樓面裝修／隔間／設備載重統計及用途活載規定。常重 γc 參考 2.4 tf/m³；D自重=h/100×γc。輸入的是使用載重，程式再組合。

可以照著輸入的範例

範例 A｜20 cm 簡支樓版單向剪力

fc′=280 kgf/cm²、λ=1、φ=0.75、h=20 cm、bw=100 cm、c=2 cm、D13（Ab=1.267 cm²、db=1.27 cm）、s=15 cm、偏移=0、Ln=4 m、γc=2.4、額外 D=0.30 tf/m²、L=0.30 tf/m²、Nu=0。採自動 d、規則配筋、均布簡支，勾選距支承面 d 適用條件。

d=17.365 cm，As=8.4467 cm²，D=0.78 tf/m²，qu=1.416 tf/m²；頁面可載入並顯示完整數值。

範例 B｜25 cm 無梁版內柱沖切

fc′=280、λ=1、φ=0.75、h=25 cm、cx=cy=40 cm、dx=22 cm、dy=20.4 cm，淨 Vu=45 tf，Mx=My=0。選「內柱彎矩計算」。d=21.2 cm，b0=244.8 cm，β=1，αs=40；三式最小值控制強度。可增加 Mx、My 觀察最大剪應力上升。

邊柱／角柱要如何輸入？

柱面須與自由邊齊平。選柱位後必須改為「輸入完整最大 vu」，填入包含彎矩傳遞及形心偏移的分析值。未填完整應力時僅顯示強度，不會出現「符合」。

離線、保存與手機操作

「下載離線版」產生單一 HTML，無外部字型或計算函式依賴。電腦直接雙擊，以 Chrome／Edge／Firefox 開啟；手機須用能執行本機 HTML 的瀏覽器或檔案檢視器。公式、圖示、說明與報告都可離線使用；規範來源及工程入口連結需連網。

手機工作頁在上方橫向切換。欄位提示長駐，觸控不需要滑鼠懸停。輸入自動存在目前瀏覽器；跨裝置或清除瀏覽資料前，請匯出專案 JSON。

計算引擎的規範對照

單位：fc′ kgf/cm²；b、d cm；Vc kgf；Mx、My tf·m。
S = min(√fc′, 26.5)
λs = min[1, √(2/(1+d/25))]
ρw = As/(bw d)
σN = min[Nu×1000/(6 bw h), 0.05fc′]
Vc = max{0, min[(2.12λsλρw^(1/3)S+σN)bw d, 1.33λS bw d]}
沖切：vc = min[1.06, 0.53(1+2/β), 0.265(2+αs d/b0)] λsλS
φVc = φVc；φvc = φvc；D/C = 需求／設計強度。

單向採表22.5.5.1(c)，Av=0<Av,min。此版不使用有剪力筋才可用的(a)式。

內柱雙軸彎矩與 Jc
a=cx+d；b=cy+d
Jy = da³/6 + ad³/6 + dba²/2
Jx = db³/6 + bd³/6 + dab²/2
γv,y = 1−1/[1+(2/3)√(a/b)]
γv,x = 1−1/[1+(2/3)√(b/a)]
vu,max = Vu×1000/(b0 d) + γv,y |My|×100000(a/2)/Jy + γv,x |Mx|×100000(b/2)/Jx

採規範 R8.4.4.2.3 的內柱 Jc，包含 d³ 項；用四角最大絕對值包絡判定。預設 γf 不使用可放寬的修正值。邊角柱的形心偏移及不對稱應力需由外部完整分析提供。
