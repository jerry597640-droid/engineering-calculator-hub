# 鋼梁開孔彎矩折減工作台 v1.0

雙擊 index.html 即可離線使用。頁面內含參數來源、操作步驟、範例與規範連結；支援真實 DOCX、列印 PDF、JSON 存取及離線 HTML 下載。

臺灣 ASD 翼板螺栓圓孔之強軸截面分析：全斷面、4.1 等效有效斷面及完全扣孔淨斷面分列。三矩形模型不含軋製圓角。預設扣孔寬為標稱孔徑 +1.5 mm。

自動容許應力僅限結實斷面且 Lb≤Lc；長梁需另案驗證 Fb。本版未自動完成孔邊局部挫屈、孔距邊距、斷裂、剪力、疲勞、耐震塑鉸及接合檢核，故只提供截面彎曲篩檢，不能以此宣稱整體設計通過。未填孔不直接套用螺栓孔 15% 規則。腹板開孔不適用。

驗證：node test.cjs；重建：python3 build.py。官方來源與查核日期已內嵌。DOCX library: docx 9.6.1, MIT license (repository vendor/docx/LICENSE)。
