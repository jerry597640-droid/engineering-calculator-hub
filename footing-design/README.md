## 計算範圍

S使用荷載做承載、滑動及趾點傾覆；U強度荷載做抗彎、單向剪力、沖切與底筋檢核。計算基腳、覆土、選用埋置柱自重，地下水浮力有獨立係數；不承拉接觸面採截切多邊形積分並平衡N、Mx、My。含新版單向剪力公式、尺寸效應、最少底筋、高沖切柱帶最少筋、實際柱帶支數、矩形短向配置、有效深度、拉力控制與直線伸展。

PASS僅代表已列檢核及輸入組合通過。沉陷、液化、柱插筋、支承壓應力、彎鉤、抗浮專項及耐震連結另核。偏心接頭、反向彎矩、邊／角柱、部分接觸及側向土壓條件可能標示REVIEW或NG。條形、聯合、筏式、樁帽、鋼柱底板與變厚基腳不在本版範圍。常重RC、無塗層竹節底筋、無孔洞／剪力筋；fc′175～700、fy2800～4200 kgf/cm²。
