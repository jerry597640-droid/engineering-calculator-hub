# 基樁分析工作台 v1.1

直接開啟 index.html 即可使用，全功能無外部字型、CDN或網路依賴。
線上位置：https://jerry597640-droid.github.io/engineering-calculator-hub/pile/

## 功能
- 現行112年規範 SPT砂土法、砂土/黏土參數法，鑽掘/閉口打入樁，圓/方實心樁。
- 原程式典型法、詳細法與SPT簡易法比較，保留公式追溯。
- 分層精確摩擦積分、地下水有效應力與樁身浮重、樁尖上下範圍平均N。
- tf / kN / kgf結果單位切換；深度曲線、土層分攤、逐點結果。
- 內嵌操作說明、資料來源、三組一鍵範例。
- JSON案件開啟/儲存、含目前案件的單檔離線版下載、CSV匯出、列印/PDF報告。
- 手機版頁籤與單欄表單，桌面側欄工作區。

## 規範
國土署《建築物基礎構造設計規範》112年版（2024-01-01生效）。
https://www.nlma.gov.tw/ch/legislation/regsearch/962
第5.3.1節，表5.3-1/5.3-2；第5.3.2節，表5.3-3。
常時推估公式 FS摩擦=2.5，FS端承=3.5，FS拉拔=5。
SPT僅限砂土；樁尖平均N使用鑽掘±1D，閉口打入上4D/下1D。

## 原始來源與差異
20121009 pile.zip，WindowsApplication1/PileCapacityAnalysis.vb。
原固定200步右端累加改分層/水位/臨界深度精確積分；內部統一kN/m/kPa。
原全剖面一個土單位重改每層天然/飽和重；樁重改用樁身面積。
α表限制0–200 kPa；φ表限制26–40°，不推測原表缺漏的第13組。
現行模式不採舊黏土SPT式，不沿用舊係數。

## 適用範圍
本工具完成單樁地盤軸向支承力推估，不能宣告完整基樁設計合格。
樁體結構、沉陷、側向力、群樁、液化、負摩擦中性面分析與試樁須另行完成。
負摩擦欄輸入已評估附加需求，只作保守淨可用量扣減。
擴底樁未含擴底體積與拉拔破壞模式，拉拔不提供合格判定。
中空、開口打入、植入樁、岩盤/卵礫石專用估算不適用。

## 離線使用

解壓後直接開啟 `pile/index.html`。計算、參數查詢、影片、JSON、CSV及Word匯出不需網路；外部官方規範連結與回到工程工具需要連線。也可用程式「下載離線版」取得包含目前案件的單一HTML。

## 重建

在完整工程工具儲存庫內執行 `python pile/build.py`，需保留 `pile/media/tutorial.mp4`、`chapters.json`、`narration.txt`、`pile/enhancements.js`、`trace.js`、`shared/calculation-docx.js`及`vendor/docx/docx-9.6.1.iife.js`。
