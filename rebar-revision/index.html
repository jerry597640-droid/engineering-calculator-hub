計算過程與舊程式對照

原程式方法一：鋼筋重心

As = ΣAs,i；d = Σ(As,i di)/As
m = fy/(0.85 f′c)；ρ = As/(bd)
Rn = [1 − (1 − mρ)²]fy/(2m)
φMn,old = 0.9 Rn b d² / 100000

原程式方法二：各列抗彎矩相加

ΣφMn,i = Σ[0.9 As,i fy(di − As,i fy/(2×0.85 f′c b))]/100000

方法二為原執行檔回溯對照值。多排分別套用混凝土壓力區，會少算共同壓力區的二次交叉項，因而高估強度；不作為修正通過的判定依據。新版以共同壓力區計算，且只有全部受拉鋼筋可降伏時才提供正式強度。

操作說明與輸入資料來源

本說明已內建於程式與離線版。桌機可由左側導覽開啟，手機可由上方導覽或工具列的「操作說明」按鈕開啟；查詢完畢按「斷面與配筋」回到輸入畫面。

使用前準備

準備核定結構圖、梁配筋詳圖、材料設計規格、混凝土配比資料及需求彎矩計算書。先確認樓層、梁號、斷面位置和彎矩方向；程式預設值是示範資料，請換成實際工程資料。兩個方案的尺寸、材料與配筋均獨立輸入。

使用流程

  1. 依核定結構圖填入原設計斷面、材料及各排主筋。
  2. 按「複製原設計到修正」，再調整修正方案尺寸、鋼筋號數、支數與排間淨距。
  3. 選正彎矩或負彎矩；第 1 排永遠是最靠近受拉面的鋼筋。方向只改變斷面顯示，兩側使用相同強度計算法。
  4. 查看強度保留比例與兩方案各項檢核；若有設計需求彎矩，填入 |Mu|，額外確認修正 φMn ≥ |Mu|。
  5. 於「計算過程」查看公式與原程式對照。列印計算書會包含輸入、配筋明細、結果及範圍；可由瀏覽器另存 PDF。

建立修正方案

先填完整「原設計」，再按「複製原設計到修正」，接著只修改需變更的欄位。此按鈕會覆蓋目前修正方案；若已有要保留的案例，先按「儲存案例」。每次變更輸入，結果與配置檢核會立即更新。

配筋模型與距離

同排鋼筋中心共線，以該排實際有支數之最大直徑定位。相鄰排中心距＝前排最大直徑/2＋淨距＋本排最大直徑/2。混合直徑時，所填排距是兩排最大鋼筋表面間的最小淨距。水平採均等淨距配置；兩側鋼筋對稱，奇數支數多的一支放右側。本頁未自動檢核上下排水平對齊；現場鋼筋須上下對齊，局部束筋、交錯排筋須另外設計。

結果怎麼看

「強度未降低」只表示修正 φMn 不小於原設計。原設計也可能不符合現行配筋要求，需查看兩方案檢核表。未填 Mu 時，需求強度顯示「未檢核」。只有修正方案通過本工具範圍內檢核，且具有效原設計基準，才顯示「本工具範圍內檢核通過」。

結果欄位閱讀方式後續動作
原設計／修正方案 φMn設計抗彎強度，單位 tf·m；不是需求彎矩Mu。有Mu時，核對修正φMn是否大於或等於需求。
強度保留比例修正φMn ÷ 原設計φMn；100%以上表示抗彎強度未降低。同時查看兩方案的全部配置檢核。
需求Mu未提供Mu填0代表未提供資料，需求強度未檢核。有需求分析結果時，輸入因數化載重組合的彎矩絕對值。
未符合／待處理項目查看保護層、水平與排間淨距、最小鋼筋量、拉力控制及降伏等項目。依未通過項目修正方案，再重新查核。
強度顯示「—」可能為輸入無效，或主筋未全部受拉降伏而超出算法適用性。閱讀提示與「計算過程」，必要時改用完整斷面分析。

適用範圍

限矩形、常重混凝土、非預力、無軸力梁的單側受拉多排配筋；f′c 175～700、fy 2800～5600 kgf/cm²。正式強度僅適用全部主筋受拉降伏，未降伏、受壓排筋、T梁或雙筋梁需改用完整應變相容斷面分析。保護層採選定環境最低值，不含耐火與特殊耐久需求。最小配筋未使用§9.6.1.3豁免。

此工具檢核彎曲強度、最小受拉鋼筋量、拉力控制及配置淨距。梁筋變更仍須另核剪力、扭力、裂縫、撓度、伸展與搭接、梁柱接頭及第18章耐震細節；改筋不可只看鋼筋面積相同。

查詢、儲存與輸出操作

  1. 計算過程：查看輸入摘要、每排面積、位置、應變、共同壓力區與強度公式；舊法僅供對照。
  2. 驗算與依據：查看規範連結、內建驗算結果與鋼筋尺度表；可按「重新執行內建驗算」。
  3. 儲存案例／匯入案例：儲存JSON資料檔，之後透過「匯入案例」繼續使用。JSON需由本程式同版本輸出，不能直接匯入Excel或原執行檔。
  4. 下載離線版：下載含目前案例與本操作說明的單一HTML檔，以瀏覽器開啟即可離線計算；手機請從下載或檔案管理中選擇支援HTML的瀏覽器開啟。
  5. 列印計算書：開啟瀏覽器列印視窗，可選印表機或另存PDF；輸出包含輸入、計算過程與操作說明。

離線與檔案

按「下載離線版」可取得單一HTML，內含目前案例、公式與操作說明；下載後雙擊即可使用，無外部程式依賴。「儲存案例」輸出JSON；「匯入案例」載入同版本JSON。資料只在目前瀏覽器內計算；工具不會自動上傳輸入。「複製原設計到修正」會覆蓋目前修正方案。

原檔案解析

來源：樑筋修正.zip內「樑筋修正.exe」（2023-03-15版本）。以.NET中繼資料與IL解析Form1.dataLoad_2、Form1.output_OK及Form1_Load，確認原／新斷面、材料、箍筋、保護層、兩側／內部主筋、排間淨距，以及兩種抗彎算法。未執行程式登入或使用認證資料。

修正項目

  • 將原程式稱作Mu的容量改稱φMn，Mu專指設計需求。
  • 取消固定0.9即判通過：先驗證每排降伏及整體拉力控制。
  • 各排抗彎相加僅作舊算法對照，避免高估。
  • 淨距、可容納寬度、反側保護層、輸入範圍不符合時提示；未降伏時阻止輸出正式強度。
