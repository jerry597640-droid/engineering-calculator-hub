# 擋土牆分析設計互動工具

單一 HTML，無 CDN 或外部程式依賴。解壓縮後直接開啟 `index.html`，即可離線計算。手機可將檔案傳至支援本機HTML的瀏覽器／檔案檢視器；若該系統不允許檔案執行JavaScript，請使用已發布的網站。

- 操作說明及各輸入欄位來源已嵌入「說明與驗證」頁籤。
- 內建原程式範例、獨立手算範例與含水止滑榫測試。
- 支援參數 JSON 備份、單檔離線下載及完整計算過程列印／另存 PDF／可編輯Word。
- 計算按每米牆長；材料單位 kgf/cm²，幾何 m，力 tf。
- 原程式公式移植與新版修正表列於網頁。

## 驗算

230 項獨立 Python 核對全部通過；網頁另含14項內建公式自檢。詳見「驗算紀錄.md」。

適用均質砂性回填與 RC 懸臂式牆。工址地勘、整體滑動、液化、沉陷、排水可靠性、施工階段、錨定與搭接仍須另核。斜背／壁面摩擦、加腋及受限動土壓之未完成互制項目會顯示待補核，不能解讀為全部設計已完成。

## 照著操作

1. 開啟index.html，先匯出目前參數。
2. 載入「獨立手算範例・乾土矩形牆」。
3. 檢查H=4.5m、牆趾0.8m、牆底厚0.4m、牆踵2.2m、φ=30°、q=1tf/m²、kh=0.1。
4. 常時有超載：抗滑FS約1.979、抗傾覆FS約4.186；地震亦須逐工況查看。
5. 按「？」查看每個欄位的定義與來源，再依地勘、結構圖說、材料及工址分析調整。
6. 檢查RC頁所有斷面，於計算過程查公式與代入值；匯出Word／PDF並備份JSON。
7. 按離線版保存目前參數與教學影片。
