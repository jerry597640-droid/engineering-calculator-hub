# 鋼筋搭接、伸展與錨定長度工具

## 使用
開啟 index.html 即可離線使用。所有 CSS、JavaScript、說明與示意圖均已內嵌；無追蹤、無資料上傳、無外部函式庫。官方規範連結與返回入口需要網路。

## 範圍
一般非耐震、非柱，同徑單支 D10～D36 竹節鋼筋；fy2800/4200/5000/5600，f′c210～700 kgf/cm²。五個計算模組：受拉伸展、受拉搭接、受壓伸展、受壓搭接、標準彎鉤新式公式。另有19個逐格核對的有限參考圖表值，與一般公式結果分開呈現。

未包含耐震接頭、柱搭接分類、成束、異徑、錨頭、鋼線網及植筋等；這些情境不輸出一般式設計值。RC03錨頭細節引用之RC11尚未提供。

## 來源與驗證
112年版《建築物混凝土結構設計規範》含113/2/19勘誤；官方來源與逐欄操作說明嵌入頁面。使用者參考圖RC02/RC03日期2024.01.15；未散布原PDF。

7200組独立Python與JavaScript公式比對通過；36個受壓搭接表格值核對通過。另驗證最小長度、A/B級邊界、高強度Ktr限制、塗層幾何等值邊界及無效輸入。數值一致性測試不是完整結構安全或法規符合性認證。

## 維護
engine.js為純計算函式，ui.js為介面。修改後執行python3 build.py組合為單一index.html。
