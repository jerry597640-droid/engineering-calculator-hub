主筋兩種輸入方式

分層配置：輸入支數、號數、y 及第一／最後一支的 x，程式在兩端之間等距排列。單支時只採第一支 x。逐支座標：每支輸入 x、y、標稱直徑及有效面積，可安排不規則位置。從分層切換到逐支會轉換目前配筋；再切回分層則每支各自成一層。

座標必須是鋼筋中心，而不是保護層距離。保護層欄為混凝土面至箍筋外側；主筋中心到混凝土面的距離至少為保護層＋箍筋直徑＋主筋半徑。逐支有效面積請按 CNS／廠商資料，不能把總面積輸入到每一支。

剪力摩擦怎麼填

Av 是整組有效垂直箍筋面積，由號數×肢數自動計算。Avf 只計穿越假定鋼骨翼板剪力摩擦面的、已充分錨定鋼筋；不得大於 Av。μ 依施工界面選 0.8（整體澆置）、0.55（硬化面粗糙處理）或 0.35（未粗糙）。本版只支援常重混凝土。Vns′ 是沿該剪力摩擦面配置剪力釘的總標稱貢獻，沒有獨立設計依據時填 0。

判讀結果

  • 「本頁檢核通過」：本版涵蓋的強度、幾何與材料條件皆通過。
  • 「強度不足」：至少一項需求／容量大於 1，調整混凝土尺寸、H 鋼、主筋或箍筋。
  • 「不符合適用條件」：即使容量大於需求，也不能依本頁數值判定合格；先解決紅色構造項目。
  • 「需補充檢核」：耐震用途或未充分支撐的施工階段尚有本版未計算的要求。

本版範圍

矩形、常重混凝土、完全包覆、對稱翼板 H 型鋼、單向強軸彎曲、無軸力、無扭矩、無開孔。正彎矩為上緣受壓；負彎矩為下緣受壓。輸入需求來自完整結構分析，程式不自動組合地震／風力／施工荷載，不計樓板 T 梁翼緣作用。裸鋼施工階段、長期撓度、裂縫、接頭、伸展錨定、剪力釘設計、防火及第九章耐震設計另核。

計算模型與保守設定

SRC 抗彎依 5.4.1 強度疊加法。鋼骨採 Mns = Fys Z；RC 採平面保持平面、εcu = 0.003、矩形等值壓力塊及鋼筋彈塑性應力。以二分法求 RC 軸向合力為零。剪力有效深度 d 取受拉側半斷面主筋的面積形心（含該側各層），不將反向面偶然受拉的補助主筋納入 d。RC 壓力塊扣除實際占用的鋼骨與主筋面積及一階矩，避免重複計入混凝土；此為較使用全寬壓力塊保守的實作設定。兩個子斷面的中性軸不同，不將圖中的 RC 中性軸誤用於鋼骨。

SRC 5.4.1 折減係數為鋼骨 0.9、RC 0.9。本程式額外檢查 112 年 RC 9.3.3.1 的拉力控制 εt ≥ Fyr / Es + 0.003；未達時顯示不符合，並僅顯示採 RC 表 21.2.2 降低 φ 的參考容量，不會標成合格。

剪力依 5.5 分配需求；RC 抗剪包含一般剪力與剪力摩擦的較小值。2.12√fc′bd、0.53√fc′bd 及 K1 = 28 使用 kgf/cm²、cm 單位，不能把 MPa 直接代入。翼板寬厚比使用全翼板寬 bf / tf，腹板淨高 hs − 2tf；本版以直角組合板計算，忽略型鋼圓角。
