# PDF 工具箱 v1.1

繁體中文的瀏覽器本機 PDF 工具。入口為 `index.html`，與工程工具入口同站發布；沒有文件上傳 API。

## 功能

- **依容量分割**：以實際輸出 bytes 檢查每份 PDF 的 MB 上限。單一完整頁面超標時會獨立輸出並明確標示，不假裝符合限制。
- **依頁數分割**：依指定頁數產生多份 PDF，保持原始頁序，最後一份可能較少。
- **合併 PDF**：多檔加入、上下移動排序、合併下載；可將合併結果接著送入分割工具。
- **縮小 PDF**：設定輸出容量上限。原檔已符合時直接提供原檔；否則先嘗試保留文字與向量的重新封裝。只有使用者勾選同意後，才將每頁渲染為 JPEG 影像並逐步調整解析度與品質。
- **實際結果核對**：顯示輸出 bytes、MB、縮小比例、頁數、採用的方法及是否達到上限。每次壓縮結果重新解析核對頁數。不保證任何 PDF 都能壓縮到任意容量。
- **ZIP 與離線**：分割檔案可整批 ZIP 下載；`offline.html` 內嵌所有 JavaScript、PDF.js 字型／CMap／WebAssembly 資源，不需 CDN 或網路即可分割、合併與壓縮。

## 操作

1. 從上方選擇「PDF 分割」、「合併 PDF」或「縮小 PDF」。
2. 匯入 PDF，設定每份容量／頁數、合併順序，或輸出容量上限。
3. 壓縮預設只重新封裝。如同意降低清晰度，再勾選影像化並選擇最低解析度。
4. 執行後檢查實際容量與頁數，再下載結果。若顯示未達容量限制，可提高上限、降低最低解析度，或使用分割。

容量採十進位：`1 MB = 1,000,000 bytes`。

## 壓縮行為與限制

- 影像化依序嘗試 150 dpi／JPEG 82%、150 dpi／58%、120 dpi／62%、96 dpi／55%、72 dpi／43%、48 dpi／32%，過濾低於使用者設定的最低解析度者；第一個實際達標的候選即停止。
- 候選若超過每頁 2,400 萬像素或任一邊 16,384 像素，會跳過該解析度；若所有允許的候選都過大，停止並提示調整設定。
- 最終輸出不採用比原檔更大的候選。來源若本來已充分壓縮，可能無法再縮小。
- 影像化保留頁數和可見頁面方向，但文字不再能選取／搜尋，向量變成像素，互動表單、連結和附件不保留；註解只保留渲染器支援的可見外觀。精細工程圖的文字、尺寸與線條須下載後核對。
- PDF 經重新封裝、分割、合併或影像化後，原數位簽章不再有效。請保留原始文件。
- 加密 PDF 須先由有權限者解除密碼。特殊 PDF／XFA 表單、損壞文件或極大型圖說可能無法處理；瀏覽器記憶體容量也會限制可處理的文件。
- 使用 Mozilla PDF.js 的 `isEvalSupported: false` 與 `stopAtErrors: true`，不執行來源文件腳本，不刻意忽略渲染錯誤。

## 維護

所有靜態檔案以本目錄為根。修改後執行：

```sh
node scripts/build-offline.mjs
node scripts/test-engine.mjs
```

壓縮與 UI 驗證腳本位於 `scripts/test*.mjs`；其環境需求依腳本說明。

第三方套件：PDF-Lib 1.17.1（MIT）、JSZip 3.10.1（MIT/GPLv3）、PDF.js 5.6.205（Apache-2.0）。CMap、字型與 WebAssembly 解碼器另附於 `vendor/PDFJS-THIRD-PARTY-LICENSES.txt`。PDF.js 核心 API 參考：<https://mozilla.github.io/pdf.js/examples/>。

`vendor/pdfjs-data.json` 為所用版本的 CMap、標準字型與 WebAssembly 資源，以 base64 彙整成單一檔案；僅在使用者同意影像化且需要進一步縮小時載入。發布必須保留 vendor 目錄及授權文件。
