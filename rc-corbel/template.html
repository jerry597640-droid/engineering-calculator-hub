GETTING STARTED

操作說明與資料來源

輸入定義、單位、來源及使用範例，離線版也能直接查閱。

建議操作順序

  1. 從結構分析取得同一控制組合的因數化 Vu 與向外水平拉力，包含托架自重及其他作用力。
  2. 依結構圖輸入材料、支承面深度、伸出長度及承壓面位置；本工具以承壓面中心作為豎向合力位置。
  3. 選定施工縫條件。有支承墊時，再輸入持續且未因數化的豎向反力 Rs。支承墊摩擦與混凝土施工縫摩擦是不同參數。
  4. 輸入實配主筋與閉合水平箍筋。先確認 aᵥ/d ≤ 1、Nuc ≤ Vu，再依 NG 項目調整尺寸、筋量或支承面。
  5. 依實際施工圖確認錨定、承壓附件、保護層及母構材。每個控制組合都須檢核；本工具不自動生成第五章完整載重組合。
  6. 下載案件 JSON 保存輸入資料；匯出計算書得到可列印的 HTML 報告。離線版 HTML 可以直接雙擊開啟，無須安裝。

可照著輸入的範例

常重混凝土、一體澆置；f′c＝280、fy＝4200 kgf/cm²；bw＝40、h＝50、端部深度＝30、伸出長度＝40、av＝20、保護層＝4 cm；承壓面 20×30 cm、錨定內側 x＝35 cm；Vu＝60 tf、Nuc＝12 tf。主筋 4-D25、水平閉合箍 6 道 D10；骨材 2 cm。

欄位／單位定義與填寫方式資料來源

判讀與調整

  • 超出方法範圍：av/d＞1 或 Nuc＞Vu，應改採第二十三章壓拉桿法等適用分析，這裡的數值不作合格依據。
  • 尺寸剪力上限 NG：增加 bw 或 d；單純增加鋼筋不能突破混凝土上限。
  • 主筋 NG：增加筋量或有效深度，再檢查淨距及實配筋量對 Ah 的影響。
  • Ah NG：增加閉合水平箍數或號數，均勻分布於主筋下方 2d/3；不是一般梁的垂直剪力箍。
  • 承壓 NG：增加實際有效承壓面積或混凝土強度。本版不採 A₂/A₁ 圍束增益。
  • 細部待確認：數值檢核通過仍須完成錨定與支承附件確認；勾選表示使用者確認，非程式自動計算該細部。

計算自我檢查

以規範公式建立獨立手算基準，再對剪跨比邊界、箍筋不足、不同施工縫、輕質混凝土、過高剪力、承壓與非法輸入進行回歸驗證。以下可在離線環境重新執行。

適用假設

材料範圍 f′c＝175～700、fy＝2800～4200 kgf/cm²；主筋及閉合箍筋同級、單排、同一有效深度。矩形支承面斷面，外端深度線性變化。剪力摩擦面採 bw×d，未計入低於 d 的額外面積或永久壓力有利效果；支承承壓採未圍束強度。輕質混凝土依種類使用 λ＝0.85 或 0.75，剪力尺寸上限另依16.5.2.5。

撓曲需求使用降伏鋼筋的壓力塊反算，並檢查降伏假設；實配撓曲強度以 εcu＝0.003、Es＝2.04×10⁶ kgf/cm²應變相容求解。若需求超出本版單筋降伏解的範圍，列為 NG，應調整斷面或另行分析。

工具提供本版涵蓋項目的分析檢核，不代替母構材、耐震接頭、錨定細部、墊材／鋼板／焊接的完整設計。圖示不作加工圖使用。
