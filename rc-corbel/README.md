# RC 托架及梁托設計工作台

依臺灣《建築物混凝土結構設計規範》112年版16.5，含113年勘誤查核。離線可用、手機适配、嵌入操作說明、輸入定義與來源、範例、詳細公式與圖示、JSON案件保存與HTML計算書。

## 執行

線上入口為同一GitHub Pages下的 `rc-corbel/`。離線直接開啟「RC托架及梁托_離線版.html」，無伺服器或CDN依賴。

開發預覽：`python3 -m http.server 8080`，開啟 `http://localhost:8080/`。

## 計算範圍

- RC外伸短懸臂托架／梁托，矩形支承面斷面、單排主筋、閉合水平箍。
- av/d≤1及Nuc≤Vu；超出時阻擋合格判斷，須另採23章壓拉桿法等適用方法。
- 同級主筋與箍筋，fy 2800～4200 kgf/cm²、f′c 175～700 kgf/cm²。
- 常重／常重砂輕質／全輕質；一體澆置／粗糙施工縫／未粗糙施工縫。
- 分別計算Af、An、Avf；Asc需求包絡、實配Asc所需Ah。
- 支承墊束制力0.32Rs（持續未因數化反力），可靠試驗低摩擦支承可採min(0.2,μpad)×1.6Rs。
- 托架φ＝0.75；獨立局部承壓檢核採φb＝0.65及圍束增益k＝1。
- 主筋扣除An後用應變相容計算撓曲強度；不把過量鋼筋一律視為降伏。

輸入的是同一控制組合的因數化作用力，不自動組合全案載重。另核母構材、地震容量設計、錨定、被支承構材、鋼板、墊材、焊接及連接。含附註與確認欄的數值通過不等於完整工程設計完成。

## 驗證

在網頁「驗證與規範」中執行內建驗證。Node回歸：

```sh
node -e "require('./engine.js'); const r=require('./verification.js').run(); console.table(r); if(r.some(x=>!x.ok)) process.exit(1)"
```

公式基準：d＝43.777cm、Mu＝12.74676tf·m、Af＝9.719681711cm²、An＝3.80952381cm²、Avf＝13.605442177cm²、Asc需求＝13.529205521cm²、Ah需求＝8.229238095cm²、尺寸剪力上限＝73.54536tf。完整回歸還包含規範邊界、施工縫、輕質混凝土及非法輸入。

## 檔案

`engine.js`純計算；`app.js`輸入、圖示、計算書；`verification.js`獨立基準與回歸；`style.css`桌面、手機與列印介面。單檔離線版由相同程式打包，保持線上／離線公式一致。
