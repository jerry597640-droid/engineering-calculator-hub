# 獨立基礎設計工作台 v1.1

由 Foundation_20121009_SourceCode.zip 的 VB.NET FormMain.vb 分析流程重建。常重 RC、矩形等厚獨立基腳，單一 RC 柱；m、cm、tf、tf·m、kgf/cm²。

完整離線套件直接開啟 `index.html` 即可離線運作，所有 CSS、JavaScript、SVG、操作說明及範例均在 HTML 內。沒有 CDN、外部字型、網路計算或自動資料上傳。HTML 可以部署在 GitHub Pages 任意子目錄。

## 操作

1. 幾何與材料：填基礎尺寸、柱尺寸與偏位、淨保護層及材料。
2. 荷載組合：輸入每個完整使用／強度組合的柱反力，保持 N、Mx、My 配對。Mx、My 須先轉移至基底水平面；程式另加柱偏位矩。
3. 地盤與穩定：採地質報告的容許承載力、土重、水位、摩擦及專案 FS。
4. 配筋：兩向號數、中心距及上下層關係。查閱剪力、有效深度與鋼筋需求。
5. 計算明細：逐組列出壓力、四側柱面彎矩、單向剪力與沖切。列印可以另存 PDF。
6. 操作與範例：可載入原尺寸重建、厚度調整、雙向偏心及部分接觸範例。各輸入欄位均有來源與提示。

7. 參數字典：40項定義、單位、圖面／反力／地質資料來源與檢核提示，可搜尋及跳回輸入位置。
8. 教學影片：6章、3分35秒、台灣女性曉臻聲線（zh-TW-HsiaoChenNeural），字幕、章節跳轉、調速及逐字稿；示範厚度調整範例。

儲存／開啟案例使用 JSON。下載離線版會包含當下輸入。手機檔案預覽器可能不執行 JavaScript，請用支援本機 HTML 的瀏覽器或檔案管理器。

## 計算修正及依據

- 基礎自重 Wc = γc L B h，修正原版漏乘厚度。
- 使用與強度載重分開；每個組合完整計算，不把不同組合最大彎矩配到同一軸力。
- 剛性基礎反力 q=max(0,a+bx+cy)，Newton 法求壓力接觸，截切多邊形精確積分核對三項平衡。
- 凈向上反力扣除基礎自重與柱區之外覆土／附載，計入水浮力。
- 按柱面計算四側彎矩；按柱面外 d 計算單向剪力；兩向鋼筋交疊採不同有效深度。
- 單向無剪力筋採臺灣112年版表22.5.5.1(c)，包含鋼筋比，尺寸效應按13.2.6.2處理。全接觸土壤承壓預設 λs=1；脫離時保守納入尺寸效應；也可選全部納入。
- 內柱沖切扣除 d/2 周界內净反力，計入兩向彎矩傳遞及 Jc；強度採表22.6.5.2三式最小值。
- 最少鋼筋採8.6.1.1，高沖切採8.6.1.2；柱帶撓曲傳遞另核。矩形短向採13.3.3.3解說的均勻全寬增量。
- 彎曲強度含 β1、鋼筋應變、φ與拉力控制檢查。
- 滑動用有效垂直力與無拉力接觸面積；被動側壓按水平力方向投影。傾覆採兩側趾點抵抗／傾覆力矩，包含水浮力。

原尺寸範例仍採原程式幾何與重力反力；配筋重建使用淨保護層7.5 cm及分層底筋（原輸入cover為8.73 cm且只扣一層）。舊土重0.91 tf/m³僅保留作測試資料，實案須由地質報告替換。

## 驗證

執行 `node tests.js`：21組工程測試，含獨立解析解及手算積分。均佈、全接觸雙向線性壓力、單軸三角形接觸、雙向角點三角形接觸、符號鏡射、接近傾覆、無平衡阻擋、自重修正、四側彎矩與剪力、沖切扣反力、單向剪力新版公式、厚度調整、水位、組合配對、偏心符號、趾點傾覆、邊柱阻擋、輸入驗證、部分接觸尺寸效應及短向分布。

基準重建（原尺寸、7.5 cm淨保護層）：Wc=34.2924 tf、S1 qmax=21.8766 tf/m²、dx=76.23 cm、dy=73.69 cm；U1單向剪力比1.18182764、沖切比0.99297277，NG。h=100 cm、fc′=280、γs=1.8、qa=30之範例，剪力比0.78758125、沖切比0.62380877，已列檢核PASS。

## 適用限制

只自動設計四邊 d/2 周界內柱之沖切；邊柱／角柱明確標示需另核。反向彎矩須上層筋，本版只檢核底筋。土壓／黏著選項啟用後需專案核定有效土體、作用點、傾覆及施工階段，不能直接當完整設計。

沉陷、差異沉陷、液化、土壤承載力推估、柱支承壓應力、柱插筋、鋼筋伸展與彎鉤、耐震連結及完整風震組合須另行設計。水浮力與自重共用wf，水力不利係數不同時，須另以專案組合核定。

PASS只代表目前輸入組合與已列檢核通過，不能取代完整基礎安全評估或技師簽證。NG代表數值不足；REVIEW代表模型需專案複核。

## 維護

`engine.js`：計算核心；`ui.js`：互動與報告；`interface.html`：樣式與殼；`build.py`：產生單檔 `index.html`；`tests.js`：工程驗算。修改後執行 `python3 build.py` 與 `node tests.js`。
