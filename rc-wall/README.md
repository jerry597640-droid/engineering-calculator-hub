# RC 牆與剪力牆設計檢核工作台 v1.1

線上：https://jerry597640-droid.github.io/engineering-calculator-hub/rc-wall/
入口：https://jerry597640-droid.github.io/engineering-calculator-hub/

適用場鑄、常重、非預力、無開孔、矩形實心牆與對稱配筋。一般牆按台灣112年版規範第11章，特殊剪力牆另按18.7節；官方規範已核對113年勘誤與2026-10-10公布資料。

## 使用

直接開啟 `index.html`。所有程式與樣式內嵌，無CDN、無需安裝，斷網可使用。官方規範連結須連網。

1. 選擇牆類型，填寫尺寸、材料與配筋。
2. 輸入同一因數化載重組合的全牆軸力、面內／面外彎矩與剪力。
3. 特殊牆線性分析另外輸入水平地震剪力VuEh與非水平地震剪力Vuns。
4. 讀取需求容量比、斷面圖、P–M圖及逐項狀態。
5. 完成適用二階效應、材質、錨定及細部設計後，勾選相應確認項目。
6. 使用「儲存案例」保存JSON；「載入案例」可繼續修改。
7. 「匯出計算書」產生包含輸入、公式、圖示、逐支鋼筋座標及檢核的HTML報告，可列印為PDF。

操作說明、各欄位定義與資料來源、3個可跟做範例，均已嵌入網頁。

## 單位

尺寸cm；力tf（1000kgf）；彎矩tf·m；材料kgf/cm²。1tf=9.80665kN。

## 核心方法

- 斷面：0.003混凝土極限壓應變、β1矩形應力塊、受壓多邊形積分、逐支鋼筋應變一致性。
- 軸力與雙向彎矩：給定Pu搜尋中性軸深度及方向，容量方向對準輸入彎矩；φPn與φMn同步折減。
- 面內剪力：11.5.4與18.7.4，包含高長比、鋼筋、淨拉力保守修正及混凝土斷面上限。
- 面外剪力：22.5.5.1(c)，無面外剪力筋，包含尺寸效應、受拉面分布筋比及軸力。
- 特殊牆：18.7.3地震剪力放大、腹板最少配筋、雙層網、牆端0.15ℓw配筋、18.7.6.3邊界應力法判定。
- 一般牆：可另加11.5.3簡易軸力法，包含中間1/3偏心限制、k、最小厚度及強度。

## 適用限制

輸入彎矩必須已包含适用二階效應。本版不自行計算整棟地震分析、P–Δ／P–δ、開孔牆、翼牆、連接梁、牆墩專用設計、施工縫剪力摩擦、基礎、錨定長度、完整邊界圍束、裂縫與撓度。特殊牆同時有面外彎矩時，雙向邊界受壓区須另分析。人工確認項目只是設計者紀錄，不是程式自動驗證。
