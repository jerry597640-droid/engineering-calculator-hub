USER GUIDE

操作說明與跟做範例

先辨識物理量，再選單位。只換算數值，不變更荷載組合、強度折減或材料性質。

01　基本操作

  1. 在左側選擇類別；手機使用工作台上方「換算類別」選單。
  2. 輸入原始數值，選擇原始單位、目標單位，結果與全部單位對照立即更新。
  3. 展開「公式與資料來源」，查看基準係數、代入式及輸入資料來源。
  4. 按「交換單位」會將完整精度的換算結果帶回輸入欄，避免重複取位造成誤差。
  5. 點「跟著做的工程範例」可載入數值及單位；「複製結果」或「匯出 CSV」可帶入計算資料。

05　常見單位辨識

  • 質量和力：1 t = 1000 kg；1 tf = 1000 kgf = 9.80665 kN。γ = ρg 是物理關係，需指定重力加速度，不是同維度換算。
  • 混凝土單位重：若設計資料寫 2.4 t/m³ 並表示自重，選「單位重」中的 tf/m³；若表示材料質量密度，選「質量密度」中的 t/m³。
  • 面載重與應力：kgf/cm²、MPa 與 tf/m² 都屬力／面積。280 kgf/cm² = 27.45862 MPa；1 tf/m² = 9.80665 kPa。
  • 溫度和溫差：0 °C = 32 °F = 273.15 K，但 10 Δ°C = 18 Δ°F。絕對溫度不接受低於 0 K。
  • 熱工：cal (IT) = 4.1868 J；cal (th) = 4.184 J。沒有 IT／th 標註的舊資料，請先確認來源採用哪種定義。
  • 慣性矩：質量慣性矩 kg·m² 與梁斷面慣性矩 m⁴ 是不同物理量。
  • 國際英制長度：ft 採國際英呎 0.3048 m，acre、rod、chain 與 acre·ft 亦據此推導，不採已停用的 US survey foot。
  • 傳統單位：台尺採 10/33 m、坪採 400/121 m²；屬明定傳統換算，現行 SI 計算宜使用 m、m²。
  • 不明欄位：44 個原版欄位因定義不明、維度不符或錯用 kips 作質量而保留待確認；部分提供明確替代單位。原版核對表會列原因。

06　離線、手機及列印

按頁首「下載離線版」，或將下載套件解壓縮後開啟 index.html。所有係數、程式、核對表及說明均已嵌入，換算不依賴網路或外部函式庫。手機可下載後使用支援 JavaScript 的瀏覽器開啟；某些檔案預覽器不執行 JavaScript。

「回到工程工具」連到線上入口，需網路。使用瀏覽器列印功能可輸出目前換算與對照表；CSV 為帶 UTF-8 BOM 的文字檔，Excel 可直接開啟。

輸入不是數字、數值溢位／下溢或低於絕對零度時，畫面會提示。畫面不儲存計算資料；離線下載後開啟會回到範例預設。

07　標準與追溯

這是單位換算工具，不進行構材承載力或規範合格判定。「符合標準」指單位定義及係數；設計係數、荷載組合與材料強度應另按該專案規範辦理。

  • BIPM：國際單位制 SI Brochure，第 9 版（目前 v4.01），SI 單位、前綴及攝氏／K 定義。
  • NIST SP 811，Appendix B.9，按物理量分類的換算因子。
  • NIST SP 811，Footnotes，國際磅、標準重力、英吋及 IT／th 定義。
  • 經濟部標準檢驗局：法定度量衡單位使用指南。
  • 教育部：長度換算表，傳統台尺與公制換算之判讀參考。
