# RC COLUMN WORKBENCH — 操作影片設計

## Style Prompt
以實際工程工作台的操作錄影為主體。使用既有深藍導覽、淺灰工作區、白色卡片，以及琥珀標記建立清楚的章節視覺；畫面大部分留給可操作的程式介面。低干擾的轉場、可讀的繁體中文字幕與明確游標，協助工程使用者跟著輸入、檢核、拖曳及匯出。影片是使用教學，數字與公式皆取自真實程式畫面。

## Colors
- #112136：品牌深藍、章節導覽與字幕底。
- #EDF1F6：工作區淺灰。
- #FFFFFF：卡片及深底文字。
- #2465B4：主要操作與容量線。
- #F4B449：章節序號、進度及操作標記。
- #187756 / #B44242：沿用程式的通過與未通過狀態，不改變工程含義。

## Typography
品牌原生介面使用 system-ui / Segoe UI / Microsoft JhengHei。影片繁中解說使用已安裝的 Source Han Sans TC（介面 fallback），保持工程術語清晰；以 DejaVu Sans Mono 顯示章節序號及時間，數字採 tabular-nums。章節標題 60 px，副標 24 px，字幕 38 px；介面以 1280×720 錄影放大至 1600×900，14 px 原生字達到 17.5 px 顯示，配合重點局部捲動與放大。

## Layout
1920×1080 橫式。頂部章節名稱及步驟摘要，中間為白卡包覆的實際程式錄影，下方預留字幕區。所有章節都使用一致的畫面配置與真實資料，3D 章節可展開工作台。游標錄在原畫面內，不另製虛假的操作動作。

## Motion
章節交界使用 0.35 秒交叉淡化，語音保留章節末 0.5 秒間隔。標題以輕微位移與淡入建立層級，章節序號使用不同入口動畫。進度列依時間線增長。介面操作本身提供必要動態，畫面不再使用任意抖動或自動縮放。

## Assets
品牌與介面由 HyperFrames capture 實際程式取得：capture/extracted/tokens.json、capture/screenshots、capture/assets。每章錄影 recordings/01.webm 至 08.webm；台灣中文旁白 audio/01.mp3 至 08.mp3；所有字幕依語音實際時間戳。程式版本與目前規範查核資訊取自本次 v1.6 PRO。

## What NOT to Do
- 不使用與品牌無關的霓虹色、全螢幕漸層或裝飾圖片。
- 不用靜態簡報替代使用者要求的實際操作示範。
- 不以只有綠色需求點宣稱所有結構檢核皆通過。
- 不把未執行的二階分析、容量剪力或完整耐久性設計列為已涵蓋。
- 不壓住輸入欄位、數字與圖面；字幕保留獨立區域。

## Capture Summary
實際擷取為現行網站相同的本地 HTML，5 張截圖、2 個原生 SVG、10 個標題、無外部字型。最終操作錄影會改採本次驗證後的 v1.6 PRO。

## 最終輸出策略
HyperFrames完成結構、對比、動態與逐章畫面檢查；其瀏覽器逐幀渲染在此環境停滯，因此最終影片改用FFmpeg直接合成同一組實際錄影、章節交叉淡化、標題淡入與旁白時軸。網頁使用可開關且手機可讀的嵌入字幕overlay；MP4另含可選繁中字幕軌，不重複燒錄文字。
