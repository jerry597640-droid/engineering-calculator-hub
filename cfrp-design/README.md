# CFRP 碳纖維補強工作台 v1.2 PRO

開啟 `index.html` 即可完全離線計算，不需安裝。線上頁同時提供「下載離線頁」、案件 JSON 保存／匯入及靜態 HTML 計算書，計算書可列印為 PDF。

## 功能
- 非預力、單筋矩形 RC 梁／一米樓板帶抗彎；含初始應變與 CFRP 脫黏上限。
- 梁／矩形柱一般剪力；完整、未錨定 U 形及兩側貼附。
- 連續環向包覆的矩形／圓形柱圍束及純軸壓上限。
- 最少層數搜尋、原柱圍束公式比對、輸入資料來源、單位與計算過程。
- 內部 N–mm–MPa；輸入 cm、kgf/cm²、tf、mm／層。

## 查核與限制
截至 2026-10-02 已查核 ACI 官方發布的 PRC-440.2-23 指南與 CODE-440.13-24 標準版本。計算採可取得的 ACI 440 指南框架，並對照 Sika 2026 年 ACI PRC-440.2-23 軟體手冊。尚未完成 ACI CODE-440.13-24 完整正文及台灣專案適用條文逐條驗證；不得將容量達標當作全面規範符合性。

抗彎混凝土採 Sika 手冊的拋物線／矩形模型，不是原 Windows 程式固定 Whitney 應力塊的逐位元移植。抗彎 φ 採 εy 到 εy+0.003 過渡。柱圍束為 Lam–Teng 模型，含圓角／尺寸／最低圍束比及最大壓應變限制；純軸壓結果不包含偏心、細長、P–M、二階與耐震韌性。剪力 Vc 採傳統 0.17√f′c·bw·d，並非所有現行 RC 規範條件的一般式。錨定、搭接、服務性、疲勞、火災與既有結構劣化需另行設計。

原壓縮檔只含 CFRP.exe 及 DLL；本版解析 .NET IL 與公式資源，未執行原 GUI、未取得完整原程式案例，也不分發原執行檔。舊柱公式只供比對，不參與新版判定。

## 驗證
`node test-engine.js`：31 項數值／邊界檢查，含獨立10萬段混凝土積分、剪力與純軸壓手算及 ACI 16.8 步驟比較。`verification.json` 記錄精確輸出。

公開 ACI 16.8 形狀係數記為 0.425；本版使用所列 SI 尺寸得到約 0.422，差約 0.7%，容許範圍為1%。需要的整數層數同為6；不把近似吻合宣稱為完全一致。

Playwright 實測桌面及320／390／768px，涵蓋離線開啟、無效資料不保留舊結果、CE連動、各模組、層數搜尋、操作說明與報告／離線下載。所有測試在本版修改後通過。

## 檔案
index.html：可直接使用的單檔（內嵌全部程式、手冊與驗算表）。
engine.js：計算核心，供獨立驗證。
test-engine.js、verification.json：數值驗證與輸出。

單位複核：舊式0.41√[f′c/(n·tf·Ef)]在f′c與Ef使用相同應力單位且tf為mm時，應力單位會抵消，本身不是單位錯誤。本版另加單位等價測試；舊柱公式中的脫黏式採原設計強度（目標欄），圍束基礎採量測強度。


## v1.1 PRO（2026-10-07）
新增需求／容量／提升比例／餘裕總覽、補強前後比較、層數容量取樣圖與可帶入層數表、完整檢核表。敏感度圖僅呈現斷面容量，不代替全部設計條件；原計算模型未改。


## v1.2 PRO（2026-10-09）
新增輸入／方案檢核／公式快捷導覽、此瀏覽器草稿保存與還原，以及 Ctrl／⌘+S 匯出案件。草稿不會自動覆蓋新開頁面的輸入，請按「還原草稿」。

「操作影片」內建 2 分鐘真實介面教學影片，提供繁體中文字幕、12 個章節跳轉、MP4／字幕下載；影片含台灣華語女性合成旁白，與12個章節對齊。手機使用原生播放器，可全螢幕觀看。完整離線套件的 index.html 與 media 資料夾須保持相對位置，即可離線計算與播放影片。「下載離線頁」單一 HTML 可離線計算，但影片使用線上網址。

影片示範梁、剪力、柱圍束、分析摘要、層數試算、公式追溯、保存案件、操作說明、計算書與離線使用。範例是教學資料，容量達標與全部設計條件完成須分別判讀。計算核心與 v1.1 相同。
