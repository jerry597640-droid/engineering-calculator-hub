    圖表與捷徑

    在「自訂工具列」勾選常用指令，即可將圖示加入上方工具列。點圖表的「釘選」即可放到結果區最上方，再點一次可回到原位。要收藏整個工具，可在工程計算工具中心點卡片上的星號。iPhone 可從 Safari 分享選單選「加入主畫面」。

    三種模式的差別

    靜力：只計入「靜態載重」，不計車軸。直接勁度法，支承處位移與轉角依設定約束。

    車輛移動包絡：靜態載重持續存在，車軸逐步通過梁，逐位置求靜力平衡。動畫與速度不產生慣性。

    動力歷時：Mü + Ců + Ku = F(t)。一致質量矩陣、Newmark β = 1/4、γ = 1/2；初始處於靜載平衡。質量比例阻尼 C = αM，α = 2ξω₁；輸入阻尼比只針對第一模態，高階模態阻尼較小。車輛為規定移動力，未模擬懸吊、路面不平或車橋耦合。

    模型與輸出

    支援 1–6 跨、每跨不同 EI／質量、固定／鉸支／滾支／自由節點。鉸支與滾支在本垂直彎曲模型具有相同約束；梁跨越內部支承時保持轉角連續，不設梁內鉸。集中力、均布／三角／梯形線載重、集中彎矩可疊加。軸重為分配至此梁的總力，左右輪分配請先換算。

    彎矩正值為下緣受拉；剪力採左段向上反力為正；撓度向上為正。動力內力由元素端平衡與分布慣性／阻尼力回復；支承反力含慣性及阻尼。曲線與包絡皆為離散取樣，減小移動步長、加密網格與縮短時間步長檢查收斂。負反力表示支承需要抗拔；本版不處理脫離接觸。

    動力時間步長自動限制至 min（使用者上限、T₁/60、最短元素長/車速/10）。未含剪切變形、軸力、材料非線性、截面強度與規範載重組合。自重預設不自動加入。
