實際主筋位置與數量

座標原點為斷面左下角，X 向右、Y 向上；單位 cm。每列 N 根沿起點→終點等分（含兩端）；N=1 時只用起點。角筋勿重複輸入。最多200列、200根；手機以配筋卡片顯示各列。

多層周邊主筋設定

各層由外向內編號，沿矩形周邊均勻配置；nx／ny含兩端角筋。層間淨距為相鄰平行主筋排的筋表面距離（非中心距）。修改設定後按「產生」套用，會覆蓋目前拖曳調整。

產生時剪力dx、dy初值採b/2、h/2，須依實際受拉筋形心核定；箍筋肢數及hx沿用輸入值，側撐確認取消勾選。多層主筋不會自動增加有效繫筋。

拖曳主筋配置

按住彩色鋼筋即可移動；手機直接按住拖曳。圖面是主筋中心座標，放開後重新計算。

整排主筋首次拖曳時自動展開為逐根，總根數及筋徑保持相同。圖面限制主筋在保護層及箍筋內緣範圍；淨距不足或其他檢核異常仍會標示。

鍵盤：圖面取得焦點後，方向鍵移動選取筋；Shift 加速10倍，Esc取消進行中的拖曳。精確座標也可在下方表格輸入。

自動尋找主筋方案

維持目前柱尺寸、材料、箍筋與全部載重組合，搜尋 D19～D36、每邊 2～10 根的周邊對稱配置，依總鋼筋面積排序。每個方案都重新檢查軸力、雙向彎矩、剪力、淨距與箍筋；採用方案後仍需完成圖說、接頭與續接設計。

按「開始配筋設計」列出本次候選範圍內的可行方案。

因數化載重組合

請輸入同一組合、同一斷面同時發生的 P、Mx、My、Vx、Vy，勿把各組合最大值任意拼成一組。P 壓縮為正、拉力為負。載重已乘係數，本工具不再自動乘載重因數。

操作順序與示範

  1. 先選柱類型與暴露環境，再填柱尺寸、材料強度、保護層及粒料。
  2. 填主筋尺寸與兩方向每邊根數；角筋只計一次。輸入箍筋尺寸與全高採用間距。
  3. 在「載重組合」輸入結構分析的同時組合內力，軸力 tf、彎矩 tf·m、剪力 tf。1 tf = 1,000 kgf。
  4. 填柱淨長、有效長度及端彎矩比，確認長細效應；超限時須由外部分析完成二階效應。
  5. 閱讀「分析總覽」各項判定；需要自動選筋時，使用「配筋設計」，再按「採用」。
  6. 「計算明細」可匯出 Word 可開啟的 .doc 計算書，也可列印另存 PDF。「下載離線版」提供完整單一 HTML，下載後直接以瀏覽器開啟。

U1：Pu=300 tf，Mx=20、My=10 tf·m，Vx=Vy=15 tf。

實際座標模式：照著輸入

  1. 選「實際位置與數量」，可按「帶入目前均勻配置」取得原有12-D25的逐根座標。
  2. 整排範例：D25、N=4、起點(6.54, 6.54)、終點(53.46, 6.54)，展開4根：X=6.54、22.18、37.82、53.46，Y均為6.54。
  3. 上排：D25、N=4、起點(6.54,53.46)、終點(53.46,53.46)。左側中間：D25、N=2、起點(6.54,22.18)、終點(6.54,37.82)。右側中間：D25、N=2、起點(53.46,22.18)、終點(53.46,37.82)。四列共12根，角筋不重複。
  4. 上述配置dx=dy=53.46、兩向箍筋各4肢、hx=15.64、D13@10。完成實際繫筋核對後勾選確認；應與原均勻模式Ast=60.804、U1 D/C=0.384387、U2 D/C=0.647231一致。

「非對稱範例」載入8-D25＋4-D19，Ast=51.996 cm²。這是操作與符號驗證用示例；內部繫筋不由主筋座標推定，側撐預設尚未確認。非對稱配置提供固定Pu的Mx–My包絡；單向P–M圖則由包絡與另一向彎矩＝0相交取得，正負分別求取。

2層以上主筋：設定、來源與範例
  1. 主筋輸入方式選「多層周邊主筋（2層以上）」，支援2～6層。這是由外向內的矩形周邊層；非規則位置仍可在座標表逐根調整。
  2. 各層填入筋徑、nx（上下各邊根數）、ny（左右各邊根數），均含角筋。每層N=2nx+2ny−4，角筋不重複。來源為柱配筋表及實際量測。
  3. 第1層中心距柱面o₁=淨保護層＋箍筋直徑＋第1層主筋直徑/2；後續oᵢ=oᵢ₋₁＋(dbᵢ₋₁＋dbᵢ)/2＋層間淨距。層間淨距取自配筋詳圖，單位cm；不同筋徑以各自直徑計算。
  4. 按「產生／更新多層座標」後，依各層實際座標逐根計算Ast及P–M容量。圖上以顏色區分來源層；不同來源層的鋼筋同樣逐對檢查淨距。柱縱筋按25.2.3檢查至少max(4 cm,1.5db,4/3粒徑)，不能直接套用梁水平層的2.5 cm。
  5. 多層箍／繫筋側撐、有效肢數與hx需依詳圖核定。剪力dx/dy初值採b/2、h/2，須改填核定之受拉筋形心深度。產生及拖曳後側撐確認會取消勾選。
  6. 仍可拖曳各根鋼筋、修改座標及匯出計算書。來源層標籤在拖曳後保留，代表原配置分組；不表示拖曳後仍是規則矩形。重新產生會覆蓋已調整座標；JSON與離線版保留各層設定及實際座標，計算以座標表為準。

照做2層範例：60×60 cm、cover=4、D13箍筋，各層D25、nx=ny=4，第2層淨距4 cm；中心偏距6.54／13.08 cm，每層12根、合計24根，Ast=121.608 cm²。載入3層範例為80×80 cm、其餘材料沿用教學值，各層D25、nx=ny=4、層間淨距4 cm；偏距6.54／13.08／19.62 cm，36根、Ast=182.412 cm²。兩例側撐預設待確認。

用滑鼠／手機拖曳主筋
  1. 選擇「實際位置與數量」，在座標表上方的「拖曳主筋配置」圖操作。
  2. 可從「選取主筋」選單找到鋼筋，或直接按住橙色主筋拖曳；目前座標以左下角為原點顯示，單位cm。
  3. 設定0.1、0.5或1 cm吸附，或選自由移動（0.01 cm）。主筋中心會限制在箍筋內緣與保護層可容納範圍。
  4. 整排N＞1的配置首次拖曳時會展開為逐根。可以先按「展開為逐根」檢視；最多200列及200根。只移動選取筋，其餘位置與筋徑不變。
  5. 放開後座標表、斷面、互制圖與檢核同步更新，側撐確認會取消勾選。淨距不足、重疊或有效深度不符會標示，需修正後再使用結果；圖面仍可繼續移動修正。
  6. 「復原上次移動」可還原最近一次圖形操作；Esc或觸控中斷會取消當次拖曳。圖面取得焦點後可用方向鍵微調，Shift放大10倍。下方表格可輸入精確座標。

照做範例：載入「非對稱範例」，選第9根D19，吸附0.5 cm，從(16,16)拖到(18,18)。總根數維持12、Ast維持51.996 cm²；彎矩容量依新的實際位置重算。需重新核對箍／繫筋側撐及有效深度，不能以拖曳圖作加工圖。

計算方法、單位與規範對照

採常重、非預力、矩形箍筋RC柱，支援均勻配筋及實際座標（各筋fy使用同一輸入材料值）。鋼筋及混凝土以平面應變相容求斷面標稱強度。矩形壓力塊採多邊形裁切，計算實際面積與形心；鋼筋應力依中心應變求得、限制於 ±fy。混凝土壓力塊內鋼筋所占面積會扣除，壓力塊跨越鋼筋時用圓弓形面積連續修正。

εcu=0.003；a=β₁c；fc≤280 時 β₁=0.85，280～560 線性下降，≥560 為0.65。
εsi=0.003(1−di/c)；fsi=clamp(Esεsi,−fy,+fy)。
Pn=ΣFi；Mnx=ΣFi yi；Mny=ΣFi xi。
εty=fy/Es；φ=0.65+0.25×clamp[(εt−εty)/0.003,0,1]。
P₀=0.85fc′(Ag−Ast)+fyAst；φPn,max=0.65×0.80×P₀。

固定Pu時，沿120個壓縮法向角度求φPn=Pu的斷面邊界，沿需求彎矩方向與相鄰邊界點連線求交點，D/C=需求彎矩合值／該方向邊界容量。非對稱配筋另使用需求點是否位於包絡內判定，避免原點在包絡外時誤判。純拉端點依主筋面積形心保留偏心彎矩。這是固定軸力下的彎矩利用率，不是三軸比例同步放大的荷載因數。曲線以離散角度內插；接近1.0時須增加解析度或用經驗證專業軟體複核。
