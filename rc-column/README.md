# RC 柱配筋設計與檢核

依台灣112年《建築物混凝土結構設計規範》及113年2月勘誤，計算矩形箍筋柱的周邊均勻配筋或實際座標配筋的軸力、雙向彎矩、剪力、細則及長細篩選。含特殊抗彎矩構架柱圍束檢核、配筋搜尋、斷面與互制圖、輸入來源、操作說明及可跟做範例。

直接開啟 `index.html` 即可離線操作，無 CDN、無外部字型或套件。`manual.html` 為可列印說明。網頁可儲存／開啟專案 JSON、下載離線版、匯出 Word 可開啟的 HTML .doc，以及列印另存 PDF。

## 主筋三種輸入方式（v1.3）

1. 每邊根數：延續nx/ny周邊均勻配置與自動搜尋。
2. 實際位置與數量：每列選筋徑、根數、起終點；N根沿直線等分含兩端，N=1只取起點。cm座標原點為左下角。可逐根、整排、混合筋徑或非對稱配置；最多200列、200根，未支援束筋。

3. 多層周邊配置：2～6層，由外向內逐層設定筋徑、nx／ny與層間淨距，產生座標後仍可逐根拖曳。每層含角筋且不重複計數。每層顏色、根數與Ast可辨識；來源層標籤保留，但容量以實際座標計算。

主筋逐根參與應變相容與力矩平衡。正Mx壓縮上側，正My壓縮右側，需與外部分析軸向／符號換算。實際座標模式的有效箍筋肢數、剪力dx/dy、耐震hx與側撐須由詳圖確認。單向圖採另一向彎矩為零的真實切片，不假定正負對稱。材料fy/fyt可直接輸入核定值；整個斷面仍採同一fc′與fy，未納入CFRP或不同材料補強。

內嵌說明含四列12-D25範例與可點選的混合非對稱範例。離線下載保留當前配筋與工況；既有JSON專案保持相容。

## 圖面拖曳（v1.2）

在實際座標模式按住主筋拖曳，或用手機觸控移動；選取筋與X/Y座標同步顯示。座標可吸附0.1、0.5、1 cm或自由0.01 cm，圖面限制保護層與箍筋內緣範圍。整排主筋首次拖曳會展開為逐根，其他鋼筋保持位置與筋徑；可復原最近一次圖形操作、Esc取消拖曳，亦可用方向鍵與Shift微調。最多200列／200根。

放開後重算容量及檢核，並取消主筋側撐確認；淨距、重疊或有效深度不符仍標示異常。輸入異常時保留編輯圖供修正，舊計算結果清除。拖曳期間不顯示舊容量。JSON專案及離線下載保存更新座標。

`drag-ui.js` 為圖形座標編輯模組，建置時內嵌單一HTML。`drag-validation.json`記錄實際滑鼠／觸控、群組展開、邊界、復原、離線及版面測試。

## 驗證與範圍

`VALIDATION.md`、`validation-results.json` 保留數值比對；外部單向與雙向公開案例最大差異小於0.1%。採應變相容、Whitney壓力塊幾何積分及逐筋力平衡，雙向檢核使用固定Pu的彎矩容量包絡線。120方向取樣已與720方向比較。

本版是斷面與指定細則檢核工具。長細柱需輸入已處理二階效應的內力；特殊構架尚需另完成接頭、強柱弱梁、容量剪力、錨定及續接。幾何圖為配置示意，箍／繫筋彎鉤與施工詳圖须由工程設計確認。程式狀態明確標示這些待完成項目。

## 重建

Node.js執行 `node verify.cjs` 及 `node custom-verify.cjs`；Python 3執行 `python3 build.py`。來源模板為 `page.html`，核心為 `core.js`；產物為 `dist/index.html` 與 `dist/manual.html`，發布時將其放置本資料夾根目錄。

官方來源：https://www.nlma.gov.tw/ch/legislation/regsearch/6874

## 多層範例與操作（v1.3）

選「多層周邊主筋」，選2～6層或自訂整數層數。每層分別填筋徑、nx/ny；內層另填與前層淨距（cm）。按「產生／更新多層座標」套用，會覆蓋既有拖曳位置。修改模板或尺寸後顯示尚未套用，既有座標才是計算依據。

60×60 cm、cover=4、箍筋D13、各層D25、nx=ny=4、層間淨距4 cm：2層偏距6.54與13.08 cm，24根，Ast=121.608 cm²。按「載入3層範例」帶入80×80 cm、36-D25，三層偏距6.54、13.08、19.62 cm，Ast=182.412 cm²。這些是操作範例，各層側撐、箍筋肢數及剪力有效深度仍需依詳圖核定。

主筋最小淨距採柱條文25.2.3，各對檢查max(4 cm、1.5倍較大主筋直徑、4/3倍粒料粒徑)，同層與跨層皆納入。產生座標不代表合格；不足時標示細則未通過，無法容納時保留原座標並提示錯誤。新增層數不自動增加箍筋肢數；產生時dx/dy採b/2、h/2初值，取消側撐確認。

`layers-ui.js`與`RCC.buildLayers`提供模板及生成器；`layers-verify.cjs`、`layers-ui-test.cjs`涵蓋獨立手算、混合筋徑、實際拖曳、離線、報表、錯誤處理及320～1440px版面。新增驗證紀錄見`layers-validation.json`及`layers-ui-validation.json`。

## 詳細計算過程（v1.3.1）

「計算明細」第5節提供實際筋徑分組面積、座標換算、軸力界限、中性軸方向與二分迭代、逐筋應變／應力、扣除占用混凝土力、圓弓形占用形心修正、兩方向淨力矩與合力加總。另列出120方向邊界與需求射線交點的插值數值、D/C、兩方向剪力代入、配筋淨距控制筋對、箍筋及長細篩選；耐震模式附圍束係數及需求代入。

逐筋狀態取鄰近需求方向的一個邊界解，D/C採兩相鄰解連線交點，兩者不混用。表格分為應變／應力及力／力矩兩張，手機在表內橫向滑動；匯出計算書包含所有載重組合的完整明細。顯示值約整，計算採完整精度。

`audit-ui.js`為唯讀明細呈現；`audit-verify.cjs`验证力與力矩加總、半圓形心及邊界交點，`audit-ui-validation.json`保存介面驗證。核心數值公式未改變，新增的是既有計算的追查資料。

## 3D P–Mx–My互制圖（v1.4）

「分析總覽」自動顯示設計強度φPn–φMnx–φMny曲面、全部載重點及目前Pu切片。滑鼠拖曳旋轉與滾輪縮放；手機單指旋轉、雙指縮放。可切換立體、俯視、P–Mx正視、P–My側視、曲面／線框、標準或精細取樣。點載重點或選單可切換組合，PNG保存目前視角。

曲面使用原RCC.capacityAtP逐個固定設計軸力建立全方向輪廓；標準29軸力層×60角，精細45層×120角。頂層是φPn,max的實際輪廓與水平蓋面，不把超過軸壓上限的曲線投影回上限；底部純拉端點保留非對稱主筋形心的偏心彎矩。繪圖不改變原120方向需求檢核；紫色切片直接採目前組合的原核心包絡。

綠／紅點僅代表軸力及雙向彎矩容量內／外，不包含剪力、穩定與配置細則。不同軸依數值範圍縮放，半透明曲面供檢視，以數值檢核判定。輸入或拖曳主筋變更時取消舊生成任務、清除舊結果，並依新斷面重建；無效或求解未收斂時不顯示不完整曲面。離線版無外部繪圖資源依賴。

`surface-core.js`為可分段中止的曲面取樣器；`surface-ui.js`為Canvas互動呈現；`surface-verify.cjs`验证原核心輪廓等價、正負對稱、純拉偏心、多層與取消，`surface-ui-test.cjs`驗證實際滑鼠／觸控、載重選取、無效資料、離線、PNG、版面及原生DOCX匯出相容。
