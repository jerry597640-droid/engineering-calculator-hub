# 鋁模板設計檢核工作台 v1.0

適用於牆、柱、梁側、梁底及樓板之鋁面板、縱肋、橫肋、背楞／龍骨、銷釘、拉片／螺桿與鋼管支撐的構件檢核。牆柱另有組立抗風斜撐與錨點分力檢核。

## 開啟與離線使用

直接開啟 `index.html` 即可，不需要安裝或連網。頁內「匯出與備份」可下載包含目前輸入的單檔 HTML、JSON 備份、Excel CSV、原生可編輯 DOCX；列印可另存 PDF。手機請使用可執行本機 HTML 的瀏覽器或本機網頁環境。

預設為縮短構件跨距的操作示範，非任何工地核定配置。所有材料及容量參考值均保留「依據待核定」狀態。「載入範例」另提供七組 A 版參考參數及敏感度範例；載入會替換目前輸入，請先備份。

## 建議順序

1. 選構件種類，核對尺寸、密度、澆置方法、速率、混凝土溫度及配比。
2. 依施工圖填面板跨距、縱橫肋與背楞的支承間距和分攤寬度。
3. 用實際材證、原廠型材圖及核定計算填 I、S、Av、E、Fb、Fv。面板、肋條與鋼背楞分開輸入。
4. 填整組銷釘、孔壁、拉片、螺桿、支柱伸長及底座之容許載重，不可輸入破斷值作容許值。
5. 查看最大 D/C、分項 OK/NG、完整計算，完成核定依據後匯出。每個欄位的 ⓘ 會連到定義與資料來源；頁內包含全部119項欄位說明。

桌面左右工作區分別捲動，圖形可切換釘選；點構件卡可查看梁模型、集中力、反力及彎矩。手機用底部輸入／結果／圖形／說明切換。

## 設計依據與單位

- ACI PRC-347-14(21)：側壓力選式、Cc/Cw、液壓上限、30Cw kPa 下限、施工活載及總載重下限。SCC、超限坍度／振動、新配比等採液壓；底部泵送至少液壓乘1.25。
- Aluminum Design Manual 2020：材料、焊接熱影響、有效斷面及局部／側向挫屈的核定依據。程式接受核定有效容許值，沒有宣稱自動實作全冊鋁設計規範。
- 營造安全衛生設施標準：官方查核115/06/30修正。第130、131及133～136條之材料、設計、組拆與支柱管理。
- 撓度預設L/360沿用參考書總則；桃工規03110 V3.0（2024/10）一般條款為L/240，請依本案契約採用。絕對3mm為示範專案值，非全國通用規定。
- 支柱與斜撐的鋼管公式是參考書ASD柱式重算；取理論軸壓、原廠實際伸長能力及底座能力之最小值。長細比限制採參考書200，超過即列NG。
- UI使用kgf、cm、mm、m、kgf/cm²及kPa；內部統一N、mm、MPa，標準重力9.80665。

原始參考為使用者提供的115年9月鋁模板支撐A版計算書。公開程式不包含原PDF及簽章、公司識別、施工圖等原始文件。

## 可手動核對的範例

- 牆高3.4m、密度2300kg/m³、T=21°C、R=1.5m/h、Cw=Cc=1：`p=7.2+785×1.5/(21+17.8)=37.547938 kPa=3828.824129 kgf/m²`。
- 拉片500×400mm：`T=p×0.5×0.4=765.764826 kgf`，對864kgf之比約0.886302。
- 梁側高0.7m、密度2300kg/m³：液壓`1610kgf/m²`。
- 樓板厚15cm：原書自重加30%衝擊`2400×0.15×1.3+25=493kgf/m²`；設計模式另加250kgf/m²施工活載後`743kgf/m²`。

「原書重算」模式沒有補足ACI施工活載，會保留待核定狀態。設計模式把原書30%衝擊另加於施工活載，採保守組合；30%是原書專案假定，並非ACI固定規定。

## 原書差異如何處理

頁內「規範與驗證」列出混用SI／重力單位、銷釘沿用不同壓力、背楞wL²/10與wL²/8混用、樓板100cm載重條帶與40cm斷面、支柱260／310／330cm不同長度，以及面板／型材合金不同卻共用容許值等問題。

原書內嵌分析圖的支承位置、連續性及集中載重，需要完整模型才能逐點重現。本工具採等跨、等EI、全跨滿載的明確模型。參考範例可能出現NG；不能只憑與原圖不同就判定原分析錯誤。

## 模型範圍

面板為1000mm寬單向條帶。梁採Euler–Bernoulli直接勁度法，含一致均布荷重節點力、均布荷重四次特解及集中力實際節點；取得全部正負彎矩、剪力及跨內撓度最大值。等分區中央集中力模型維持總荷重守恆。

各構件按使用者核定的分攤寬度獨立檢核。連續構件最大支承反力係數傳至支柱。接頭偏心、邊框焊道細部、錨點拉剪交互作用、不等跨、懸臂、施工活載花載、整體側移／抗傾覆、多層回撐及下層樓板承載未自動分析，應另有核定計算。

## 程式與驗算

```sh
python3 build.py
node tests/verify.cjs
npm install --no-save --no-package-lock jsdom@26.1.0
node tests/verify-ui.cjs
```

`engine.js`為純計算核心；`app.js`包含119項參數說明、互動及匯出；`style.css`為桌面及手機介面；`template.html`經`build.py`組成不依賴網路的`index.html`。

驗證涵蓋單／二／三跨閉式解、中央及偏心集中力、力與力矩平衡、ACI公式分支與邊界、材料容量、支柱挫屈及無效輸入；DOM事件測試涵蓋模式、範例、釘選、篩選、匯出及離線重開。詳見`tests/validation.json`及`tests/ui-validation.json`。DOCX匯出另以ZIP/XML及python-docx重新開啟確認。

瀏覽器實際幾何及手機觸控檢查以發布後的實測紀錄為準；DOM事件測試不等於真實裝置驗證。
