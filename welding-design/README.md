# 焊接分析設計 v1.6

完整解壓縮 ZIP，保持 index.html 與 media 資料夾相鄰。雙擊 index.html 可離線計算、查說明及播放台灣華語女聲旁白影片。單一 HTML 下載只包含計算、說明及逐字稿；影片須使用完整離線包。

## 分析形式

|形式|計算範圍|有效面積／主要輸入|
|---|---|---|
|平面等腳填角焊群|三向力與偏心矩、同一焊腳、共平面焊線；直線與完整平面圓環|喉厚 s/√2；各端點cm、焊腳mm、荷重kg或tf|
|CJP全滲透開槽焊|同心單獨拉力或剪力|較薄板厚×有效長度；相稱焊材與核定全滲透接頭|
|PJP部分滲透開槽焊|同心垂直有效面積拉力，或平行於焊軸剪力|核定有效喉厚×有效長度；喉厚不能直接以槽深代替|
|塞孔焊|同心、接觸面平行剪力、等尺寸孔均分|nπd²/4；孔徑、數量、板厚、焊厚、孔距|
|塞槽焊|同心、接觸面平行剪力、等尺寸槽均分|n[b(l−b)+πb²/4]；封閉兩端半圓槽；l包含端部|
|原版九型查表|原附件cws()/wei()的係數比對|保留原九型係數及圖示，禁止外插|

其他形式頁使用台灣第10章；不會沿用填角焊頁的AISC選項。填角焊與其他形式分開儲存／匯入及匯出Word。母材可用承載必須由同一設計方法及受力方向的外部計算書取得；填0為待確認。教學值不預設接頭／WPS已確認。

## 按範例輸入

1. 填角焊按「載入教學範例」：台灣ASD、E70、焊腳6mm、兩板12mm。
2. 焊線為(0,0)→(0,30)及(20,0)→(20,30)，座標cm。
3. 施力位置(25,15,0)cm，Py=−10000kg，其餘力和額外力矩0。自動計偏心矩，不要重填。
4. 利用率約0.601，強度所需焊腳約3.61mm。材料、尺寸與未涵蓋項目仍須核對。
5. 其他形式頁先選形式、按「載入此形式教學值」。CJP拉力局部容量54000kg；PJP剪力約26576.03kg；塞孔約20455.31kg；塞槽約68823.68kg（最終精確值以程式為準）。Rbm先填0，結果為待確認。
6. 白色端點可改長度與方向，藍線可平移，復原回到上次配置。手機以觸控拖曳並可直接輸入座標。
7. 「輸入參數辭典」可搜尋46項定義、來源及範例；點選欄位也會顯示說明。
8. 「操作影片與旁白」提供九章導覽、播放速度及逐字稿。

kg表示公斤力kgf；應力kg/cm²、線力kg/mm、力矩kg·m。1kgf=9.80665N。幾何慣性積為線積分mm³，不是實體截面mm⁴。

- 台灣建築物鋼結構設計技術規範：官方目錄96年發布、99年修正（該修正為第13.2節）。本次直接核對ASD與極限設計第10章官方PDF，包含開槽焊有效面積、表10.2-3最小喉厚、孔槽尺寸、表10.2-5強度。

## 驗證與限制

Node.js：verify.cjs（解析解、獨立積分、旋轉不變性）、verify-units.cjs、verify-drag.cjs、verify-joints.cjs。拖曳測試請在本資料夾執行。桌面／390px手機、實際滑鼠拖曳及復原、參數搜尋、Word下載已檢查。

未包含母材完整破壞模式、HSS空間有效焊長、混合焊接形式、其他形式偏心或拉剪共同作用、疲勞、耐震細部、施工品質自動認證。PJP雙面有效喉厚總和只做保守包絡篩檢，每側仍需依正式詳圖及WPS確認。
