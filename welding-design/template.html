操作說明與資料來源

載重單位：kgf / tf

頁面頂端可切換「kgf（公斤力）」與「tf（公噸力）」。工程圖面常寫的 kg 載重，在本程式以 kgf 表示力；1 tf = 1000 kgf，1 kgf = 9.80665 N。切換時會自動換算所有作用力、額外力矩及原版查表 Pv / Ph，座標及焊腳尺寸維持原單位。

例如 10 tf = 10000 kgf；1 tf·m = 1000 kgf·m。結果區與詳細計算表各有單位選單，可獨立於輸入單位選擇 kg、tf 或 N，兩個結果選單同步。預設 kg：合力 kg、力矩 kg·m、焊線需求與容量 kg/mm、應力 kg/cm²（kg 皆代表 kgf）；公式以 N、mm、MPa 的 SI 單位計算後換算顯示。JSON 以 tf / tf·m 儲存計算資料並記錄輸入及結果單位，舊版 JSON 可直接匯入。

建議操作順序

  1. 依設計準則選擇台灣規範或 AISC，指定 ASD / LRFD。ASD 輸入服務載重組合，LRFD 輸入已係數化組合。
  2. 依材料證明與焊接程序輸入焊材分類、焊腳、兩側板厚。
  3. 選擇快速配置或輸入各焊線有效端點。所有座標採同一原點，圖示可確認輸入。
  4. 輸入同一組合的力、施力位置和額外自由力矩。切勿再填入程式已自動算出的偏心矩。
  5. 檢查利用率、最小與最大焊腳、有效長度；查看控制點與詳細公式。
  6. 匯出 JSON 保存參數。列印可輸出 PDF；下載 HTML 可離線使用。

操作重點與常見疑問

  • 修改欄位後結果立即更新；切換 ASD / LRFD 不會自動調整載重或產生組合，須自行輸入相應組合。每個組合分開計算與保存。
  • 快速配置的 L、K 定義依型式與平面圖確認；圓形 L 是直徑、圓心是 (0,0)。按「套用配置」後，請重新核對載重位置，因載重保留原值。
  • 端點與施力位置採同一座標原點。X 向右、Y 向上、Z 朝向觀看者；力與自由力矩可填負值，力矩正向依右手定則。
  • 平面圖金色點為焊群重心，紅色圈為最大需求控制點；查看「詳細計算過程」可核對幾何、合力與重心力矩。
  • 利用率 ≤ 1 只是焊材強度檢核；亦須確認尺寸、有效長度與適用範圍。原版九型查表用於歷史結果比對。
  • 手機可左右滑動功能導覽及較寬的輸入表；點選欄位後直接修改。需要查詢時切換至本頁，再返回「群組彈性分析」繼續輸入。
  • 「匯出輸入資料」下載 JSON；「匯入輸入資料」選取已保存 JSON 還原參數。「列印 / PDF 報告」開啟瀏覽器列印，目的地選「另存為 PDF」。
  • 離線 ZIP 解壓後開啟 index.html；亦可使用「下載離線 HTML」保存完整程式。修改參數後請重新匯出 JSON 保存案件資料。
如何看結果

利用率 ≤ 1 代表本計算模型的焊材需求未超過可用強度。所需焊腳僅由強度決定，仍須滿足尺寸與施工要求。即使顯示「焊材與尺寸檢核符合」，也不代表接合部整體完成設計。

自訂不對稱焊線與面外彎矩

採完整 Ix、Iy、Ixy 分析，不對稱焊線的彎矩與應力會耦合。共線焊線不能抵抗所有方向的面外彎矩，程式在退化斷面時停止計算。

離線、手機與保存方式

下載的 HTML 不需要外部函式庫、字型或連線；以 Chrome、Edge、Safari 開啟即可。外部規範連結需要網路。手機輸入表可左右滑動，欄位點選後可編輯。匯出 JSON 保存目前參數；載入 HTML 時不會自動保存其他修改，修改後請重新匯出或下載。

原版比對與新版結果不同的原因

查表版使用附件 C 值與方向修正；彈性分析版按焊線幾何直接求線力，未採方向強度增益，兩者設計模型不同。新版另使用精確單位換算、完整慣性積，並取消原版超表範圍外插與第一條焊線的人為微小位移。

本版適用範圍

適用同焊腳、等腳、平面填角焊群組的靜力彈性分析。圓環採平面圓形，不代表兩根圓管相交的空間焊道。CJP、PJP、塞焊、槽焊、混合焊腳、塑性瞬心設計、疲勞、耐震需求與單面焊局部彎曲需另用對應規範。母材檢核需要母材強度、淨斷面與破壞路徑，本輸入表沒有這些資料，故不提供整體合格結論。

修正與差異紀錄

  • 舊程式只用 Ix / Iy 分別計面外彎曲，新版加入 Ixy，支援非對稱焊線。
  • 舊程式第一条焊線用 10⁻⁶ 修補，新版採退化斷面判斷。
  • 舊報表多筆座標誤取第一筆 Y / z，新版每列獨立處理。
  • 旧版查表容許超出範圍外插，新版禁止外插；負方向載重改用群組分析。
  • 焊線重疊、空欄、零長、非法材料與退化幾何會停止判定。
