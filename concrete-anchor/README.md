# 混凝土錨栓設計與檢核工作台 v3.0

開啟 `index.html` 即可使用，不需網路或安裝程式。計算採台灣112年《建築物混凝土結構設計規範》第17章（含113年勘誤），不是ACI318-25的完整實作。

## 功能

- 常重混凝土、規則矩形或自由座標1～9支同規格錨栓；預埋擴頭螺栓、錨釘、J/L彎鉤、後置膨脹／擴底／螺紋／黏結式。
- 整組因數化載重之全拉力彈性分配，或外部分析所得逐支受力。
- 鋼材拉剪、混凝土拉破、拔出、脹破、握裹、持續拉力、剪破、撬破、拉剪互制及配置檢核。
- 採超額強度輸入載重的耐震設計路徑；有需確認項目時不判定完成。
- 有效埋深掃描、手機操作、案件JSON、詳細計算報告HTML、列印成PDF、內嵌欄位來源與範例。
- 返回工程工具入口。

## 適用限制

本版不求解底板受壓接觸、底板撬力與柔性、錨栓彎曲、剪力榫、替代錨定鋼筋、混凝土構材整體承載、高周次疲勞／衝擊、輕質混凝土、塑鉸區、特製預埋件、灌漿錨栓及貫通螺栓。

三／四面近邊拉破，以及狹窄薄構材之剪破須專項分析。本版辨識後會顯示「待補資料／專項檢核」，不作完成判定。整組簡易受力分配如出現壓力錨栓，截斷後結果僅供診斷，不可用於設計；應改輸入含接觸分析所得逐支受力。

群錨子群以矩形投影聯集保守檢核。剪破以最近排容量對比較群剪力絕對值總和；斜向作用採總剪力，純平行作用依規範採2倍。撬破按剪力絕對值權重建立保守偏心。邊緣脹破以最小單支容量對全部拉力，未使用群錨容量增益。結果可能比專業商品設計軟體保守；所有保守處理均於介面說明。

後置機械式Np必須由試驗取得；黏結式τcr、τuncr及尺寸限制必須對應實際認證／工況。未提供資料不會自動帶入假想的品牌容量。實際建築物須確認第17.10節耐震要求，預設非耐震案例僅作手算範例。

## 單位

輸入cm、cm²、kgf/cm²、tf及tf·m，內部kgf與cm。1tf=1000kgf、1tf·m=100000kgf·cm，1kgf=0.00980665kN。結果可顯示tf/kgf/kN。

## 驗證與重建

```bash
node tests.cjs
node ccd-tests.cjs
node build.cjs
```

48項工程測試（原28項加CCD與多組合20項）涵蓋手算、受力平衡、群效應、φ、持續拉力、耐震折減、資料缺漏與範圍保護。詳細結果在 `validation-results.json` 與 `ccd-validation.json`。另有25項介面、手機觸控、報告與離線檢查，結果在 `ccd-ui-validation.json`。原始碼重建需Node.js，離線使用HTML不需Node.js。

## v3 CCD圖形、自由配置與載重組合（2026-10-11）

- 於「08 CCD／載重組合」查看2D拉破表面投影、剪破邊面展開與可旋轉3D破壞錐體。青色投影的聯集面積直接對應本次控制子群／自由邊的計算，不重複計入交疊。
- 圖形可縮放25～400%，支援＋／−按鈕、倍率滑桿、滑鼠滾輪、手機雙指、鍵盤＋／−。2D空白處可平移，3D拖曳可旋轉；「適合視窗」還原倍率與平移，「重置視角」另還原旋轉。縮放不改輸入或計算。
- 規則矩形可轉為自由配置。每支填x、y、da、hef、Ase,N、Ase,V，並可納入／排除、增刪或在2D拖曳；最多9支。固定混凝土邊界時，移動錨栓會同步調整最外排中心邊距。座標與力矩均以定位原點(0,0)為基準。
- 底板Bx、By、Ex、Ey依底板製造／定位圖輸入，只提供配置圖，不自動求解接觸、承壓與撬力。四方向可指定無真實自由邊；該方向不裁切投影，也不建立虛構剪破邊。
- 最多12組完整因數化載重；各組含N、Mx、My、Vx、Vy、Tz及持續拉力比例。自動顯示最大互制DCR，也可鎖定一組。編輯組與顯示組分開，報告採顯示組的完整載重，保留全部組合狀態，缺漏組不能被控制組的符合掩蓋。
- CCD頁可在cm／tf及mm／kN間換算；主工作台仍採cm與tf。單位切換只換算顯示與輸入，不重算或改變物理量。
- 內嵌操作說明與參數字典新增定義、資料來源、載重原點、互制依據與可照著輸入的兩組範例。案件JSON與離線HTML保存全部配置與組合。原台灣國語影片繼續提供基本操作教學。

同群錨需同型式、同埋深、同直徑、同有效面積與同勁度。異規格保留圖形及診斷，但列「待專項設計」。受壓接觸、特殊狹窄幾何及ACI318-25完整計算仍不在本版完成判定範圍。多組合案件不提供單組埋深搜尋建議；須逐組檢核候選後再確認全部包絡。

### 可照著輸入的範例

按「載入多組合範例」：四支M20、hef=20cm、座標(±10,±10)cm、四邊距25cm、ha=40cm、fc′=280kgf/cm²、Ase,N=Ase,V=2.45cm²。

| 組合 | N tf | Mx tf·m | My tf·m | Vx tf | Vy tf | Tz tf·m |
|---|---:|---:|---:|---:|---:|---:|
| LC1 基本作用 | 8 | 0.3 | 0.2 | 1.2 | 0.6 | 0.1 |
| LC2 反向剪力 | 9.5 | 0.4 | −0.2 | −2 | 1 | 0.1 |

LC2為本範例控制組，程式會明確顯示其已計算項目不符合；範例用來說明包絡操作，不能當作實案設計值。
