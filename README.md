# 工程計算工具入口

圖示連結入口，收納 7 項工程計算工具。

- 點選圖示或名稱，在新分頁開啟原工具。
- 全部工具名稱、網址、分類與用途說明可編輯。
- 新增工具時可輸入新分類，保留擴充。
- 分類、搜尋、常用收藏及手機版面。
- JSON 匯入採合併，支援清單備份與裝置搬移。
- 可下載包含目前清單的離線入口頁；線上工具仍需網路。

個人清單存在目前網址的瀏覽器 localStorage，不會自動同步至 GitHub 或其他裝置。清除網站資料前請備份。

## GitHub Pages

以 main 分支、根目錄發布。無外部依賴或建置步驟。
